# Dependency Injection (DI) in FastAPI

This is one of FastAPI's most powerful features and a favorite interview topic.

Many beginners see:

```python
from fastapi import Depends
```

and think:

```text
Some FastAPI magic 😅
```

But in reality, it solves a huge software engineering problem.

---

# The Problem Without Dependency Injection

Imagine a College Management System.

Every API needs:

```text
Database Connection
Authentication
Current User
Logger
Configuration
```

Without DI:

```python
@app.get("/students")
def get_students():

    db = connect_db()

    user = verify_token()

    return {"students": []}
```

---

Another route:

```python
@app.get("/courses")
def get_courses():

    db = connect_db()

    user = verify_token()

    return {"courses": []}
```

---

Another route:

```python
@app.get("/faculty")
def get_faculty():

    db = connect_db()

    user = verify_token()

    return {"faculty": []}
```

---

Notice:

```text
Repeated Code
Repeated Code
Repeated Code
```

Bad design.

---

# What is Dependency Injection?

Dependency Injection means:

> Instead of creating objects yourself, FastAPI provides them when needed.

Think:

```text
Route
  ↓
Needs Database
  ↓
FastAPI Injects Database
```

---

# Real-Life Example

Imagine a classroom.

Student:

```text
Sir, I need a marker.
```

You provide it.

Student doesn't buy a marker every time.

This is:

```text
Dependency Injection
```

---

# First Dependency

## Step 1

Create dependency function.

```python
def get_message():
    return "Hello Student"
```

---

## Step 2

Inject dependency.

```python
from fastapi import FastAPI, Depends

app = FastAPI()

def get_message():
    return "Hello Student"

@app.get("/")
def home(
    message: str = Depends(get_message)
):
    return {
        "message": message
    }
```

---

Request:

```http
GET /
```

Response:

```json
{
  "message":"Hello Student"
}
```

---

# How FastAPI Executes This

Request arrives.

```text
GET /
```

FastAPI sees:

```python
Depends(get_message)
```

Runs:

```python
get_message()
```

Returns:

```python
"Hello Student"
```

Injects into:

```python
message
```

Then route executes.

---

# Visual Flow

```text

   ↓

   ↓
Return Value
   ↓
Inject into Route
   ↓
Route Executes
```

# Sub-Dependencies

One dependency can depend on another dependency.

This is called:

```text
Sub Dependency
```

---

Example

## First Dependency

```python
def get_token():

    return "abc123"
```

---

## Second Dependency

```python
def get_current_user(
    token: str = Depends(get_token)
):

    return {
        "user":"Ravi",
        "token": token
    }
```

---

## Route

```python
@app.get("/profile")
def profile(
    user = Depends(
        get_current_user
    )
):

    return user
```

---

Execution Flow

```text
Request
   ↓
get_current_user()
   ↓
Needs Token
   ↓
get_token()
   ↓
Token Returned
   ↓
User Returned
   ↓
Route Executes
```

# Dependency Caching

Very important interview topic.

---

Suppose:

```python
def get_db():

    print("DB Created")

    return "DB"
```

---

Route:

```python
@app.get("/")
def home(
    db1 = Depends(get_db),
    db2 = Depends(get_db)
):

    return {}
```

---

Question:

How many times does:

```python
get_db()
```

execute?

---

Most beginners answer:

```text
2 Times
```

Wrong.

FastAPI caches dependency results per request.

---

Actual:

```text
1 Time
```

Result reused.

---

Visual

```text
Request
   ↓
get_db()
   ↓
Result Cached
   ↓
db1 Uses Cache
db2 Uses Cache
```

---

# Demonstration

```python
from fastapi import FastAPI, Depends

app = FastAPI()

def get_db():

    print("DB Connected")

    return "Database"

@app.get("/")
def home(
    db1=Depends(get_db),
    db2=Depends(get_db)
):
    return {
        "db1": db1,
        "db2": db2
    }
```

---

Console:

```text
DB Connected
```

Only once.

---

# Disable Cache

Rarely needed.

```python
Depends(
    get_db,
    use_cache=False
)
```

Now executes every time.

# Common Dependency Patterns

These are used in almost every FastAPI project.

---

# Pattern 1: Database Dependency

```python
def get_db():

    db = SessionLocal()

    try:
        yield db

    finally:
        db.close()
```

---

Route

```python
@app.get("/students")
def students(
    db = Depends(get_db)
):
    pass
```

Industry standard.

---

# Pattern 2: Current User

```python
def get_current_user():

    return user
```

---

Route

```python
@app.get("/profile")
def profile(
    user = Depends(
        get_current_user
    )
):
    pass
```

Used everywhere.

---

# Pattern 3: Admin Authorization

```python
def get_admin(
    user=Depends(
        get_current_user
    )
):

    if user["role"] != "admin":
        raise HTTPException(
            403,
            "Access Denied"
        )

    return user
```

---

Route

```python
@app.get("/admin")
def admin_dashboard(
    admin=Depends(get_admin)
):
    pass
```

---

# Pattern 4: Pagination

```python
def pagination():

    return {
        "page": 1,
        "limit": 10
    }
```

---

Route

```python
@app.get("/students")
def students(
    page=Depends(
        pagination
    )
):
    pass
```

---

# Pattern 5: Settings Dependency

```python
def get_settings():

    return {
        "app_name":
        "Student Portal"
    }
```

---

Route

```python
@app.get("/")

    )

```

# Complete Example

```python
from fastapi import FastAPI, Depends

app = FastAPI()

def get_db():
    return "DB Connection"

def get_current_user():

    return {
        "id": 1,
        "name": "Ravi"
    }

@app.get("/students")
def students(
    db=Depends(get_db),
    user=Depends(
        get_current_user
    )
):

    return {
        "database": db,
        "user": user
    }
```

---

Response

```json
{
  "database":"DB Connection",
  "user":{
      "id":1,
      "name":"Ravi"
  }
}
```

# Interview Questions

### What is Dependency Injection?

A design pattern where dependencies are provided automatically instead of being created manually.

---

### Which FastAPI utility is used for DI?

```python
Depends()
```

---

### What is a dependency?

A function that provides reusable logic or resources.

---

### What is a sub-dependency?

A dependency that depends on another dependency.

---

### Does FastAPI cache dependencies?

Yes.

Per request.

---

### How to disable dependency caching?

```python
Depends(
    dependency,
    use_cache=False
)
```

---

# Golden Rule

Think of dependencies as reusable building blocks.

```text
Authentication
      ↓
Dependency

Database
      ↓
Dependency

Authorization
      ↓
Dependency

Settings
      ↓
Dependency

Pagination
      ↓
Dependency
```

Instead of writing the same code in every route, create dependency functions and let FastAPI inject them automatically.

This is one of the reasons FastAPI applications stay clean even when they grow to hundreds of APIs. 🚀
