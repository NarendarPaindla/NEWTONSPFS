# Static Routes vs Dynamic Routes in FastAPI

This is one of the most important concepts in API design.

Many students get confused between:

```text id="gln78e"
Static Routes
Dynamic Routes (Path Parameters)
```

Understanding this properly will make Path Parameters crystal clear.

---

# What is a Static Route?

A Static Route has a fixed URL.

Example:

```python id="xsyvye"
from fastapi import FastAPI

app = FastAPI()

@app.get("/students")
def students():
    return {"message": "All Students"}
```

---

URL:

```http id="s31v6h"
GET /students
```

---

Response:

```json id="z7c8v1"
{
  "message":"All Students"
}
```

The URL never changes.

---

# What is a Dynamic Route?

A Dynamic Route contains variable values.

Example:

```python id="9wt8hf"
@app.get("/students/{student_id}")
def get_student(student_id: int):
    return {
        "student_id": student_id
    }
```

---

Now URL can change.

```http id="w7h6f9"
/students/101
```

or

```http id="3h9zlw"
/students/202
```

or

```http id="hmx9yh"
/students/999
```

Same route.

Different values.

---

# How FastAPI Sees It

Route:

```python id="wnn94q"
@app.get("/students/{student_id}")
```

FastAPI understands:

```text id="k8wmvi"
/students/ANY_VALUE
```

---

Examples:

```text id="0qg0xt"
/students/1
/students/2
/students/100
/students/500
```

All match.

# Why Dynamic Routes Exist

Imagine not using dynamic routes.

You would need:

```python id="ux76wk"
@app.get("/students/1")

@app.get("/students/2")

@app.get("/students/3")

@app.get("/students/4")
```

For:

```text id="7b0tqb"
10,000 Students
```

Impossible.

---

Instead:

```python id="wbup0l"
@app.get("/students/{student_id}")
```

One route handles all students.

# Route Matching Priority

This is very important.

Suppose:

```python id="mofh5z"
@app.get("/students/me")
```

and

```python id="zhc0qf"
@app.get("/students/{student_id}")
```

exist.

---

Request:

```http id="dh1b52"
/students/me
```

Which route runs?

---

Answer:

```text id="0c7dvb"
Static Route
```

FastAPI gives priority to static routes.

---

Correct Order:

```python id="f2iy5q"
@app.get("/students/me")
def current_user():
    pass

@app.get("/students/{student_id}")
def student(student_id:int):
    pass
```

---

# Static vs Dynamic Comparison

| Static Route            | Dynamic Route               |
| ----------------------- | --------------------------- |
| Fixed URL               | Variable URL                |
| No Parameters           | Uses Path Parameters        |
| `/students`             | `/students/{id}`            |
| Same Response Structure | Depends on Parameter        |
| Used for Collections    | Used for Specific Resources |

# Common Beginner Mistakes

## Mistake 1

Wrong:

```python id="xkk8k3"
@app.get("/students/student_id")
```

This is static.

URL literally becomes:

```text id="vgsjzt"
/students/student_id
```

---

Correct:

```python id="m0nzy8"
@app.get("/students/{student_id}")
```

---

## Mistake 2

Route Variable Name Mismatch

Wrong:

```python id="w2ndml"
@app.get("/students/{student_id}")
def get_student(id:int):
```

---

Correct:

```python id="bfvw0r"
@app.get("/students/{student_id}")
def get_student(student_id:int):
```

Names must match.

# Interview Questions

### What is a Static Route?

A route with a fixed URL path.

Example:

```http id="0v7uxw"
/students
```

---

### What is a Dynamic Route?

A route containing variable values using path parameters.

Example:

```http id="nbq85n"
/students/{student_id}
```

---

### Why use Dynamic Routes?

To access specific resources without creating separate routes for each resource.

---

### Which route gets priority?

```text id="v3s3ce"
Static Route
```

gets priority over dynamic routes.

---

# Golden Rule

Ask yourself:

### Am I accessing a collection?

Use:

```http id="lllkgi"
/students
/products
/orders
```

Static Route.

---

### Am I accessing a specific item?

Use:

```http id="x86v2r"
/students/101
/products/500
/orders/9001
```

Dynamic Route.
