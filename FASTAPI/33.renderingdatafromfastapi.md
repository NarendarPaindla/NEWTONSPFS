# Topic 1: Rendering Data from FastAPI

Imagine student data comes from backend.

```python
students = [
    {
        "id":1,
        "name":"Ravi"
    },
    {
        "id":2,
        "name":"Kiran"
    }
]
```

We want to display it in HTML.

---

# Step 1: FastAPI Route

```python
from fastapi import FastAPI, Request
from fastapi.templating import Jinja2Templates

app = FastAPI()

templates = Jinja2Templates(
    directory="templates"
)

@app.get("/students")
def students(request: Request):

    students_data = [
        {
            "id":1,
            "name":"Ravi"
        },
        {
            "id":2,
            "name":"Kiran"
        }
    ]

    return templates.TemplateResponse(
        request=request,
        name="students.html",
        context={
            "students": students_data
        }
    )
```

---

# Step 2: Template

students.html

```html
<!DOCTYPE html>
<html>

<body>

<h1>Student List</h1>

<ul>

{% for student in students %}

<li>

{{ student.id }}
-
{{ student.name }}

</li>

{% endfor %}

</ul>

</body>

</html>
```

---

# Output

```text
Student List

1 - Ravi

2 - Kiran
```

# Topic 2: Forms Posting to FastAPI

This is how traditional websites send data.

```text

  ↓
```

# Complete Working Example

## main.py

```python
from fastapi import (
    FastAPI,
    Request,
    Form
)

from fastapi.templating import (
    Jinja2Templates
)

app = FastAPI()

templates = Jinja2Templates(
    directory="templates"
)

@app.get("/register")
def register_page(
    request: Request
):

    return templates.TemplateResponse(
        request=request,
        name="register.html"
    )

@app.post("/register")
def register_student(

    name: str = Form(...),

    email: str = Form(...)

):

    return {
        "message":"Registered",
        "name": name,
        "email": email
    }
```

# Form Submission with Redirect

Usually after successful registration:

```text
Don't Stay On POST Route
```

Redirect.

---

```python
from fastapi.responses import RedirectResponse

@app.post("/register")
def register_student(

    name: str = Form(...)

):

    print(name)

    return RedirectResponse(
        url="/success",
        status_code=303
    )
```

# Golden Rule

```text
Python Data
      ↓
context={}
      ↓
Jinja Template
      ↓
HTML Page

--------------------------------

HTML Form
      ↓
POST Request
      ↓
Form(...)
      ↓
FastAPI
```

This is the complete foundation of **Server-Side Rendered FastAPI applications**, and it's exactly how admin panels, dashboards, ERP systems, HRMS portals, and many internal enterprise tools are built. 🚀
