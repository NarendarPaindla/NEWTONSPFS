# Swagger UI & ReDoc Auto Documentation

One of the biggest reasons developers love FastAPI is:

> You write the API once, and FastAPI automatically creates professional documentation.

In many frameworks:

```text
Write API
     ↓
Write Documentation Manually
```

In FastAPI:

```text
Write API
     ↓
Documentation Generated Automatically
```

This is a huge productivity boost.

---

# Why Documentation Matters?

Imagine you create an API.

```http
GET /students
```

How will frontend developers know:

* URL?
* Method?
* Parameters?
* Request Body?
* Response Format?

Without documentation, they must ask backend developers repeatedly.

# What is Swagger UI?

Swagger UI is an interactive API documentation interface.

FastAPI automatically generates it.

---

# What is ReDoc?

ReDoc is another documentation interface.

It looks cleaner and more professional for reading API specifications.

# FastAPI Gives Both

When you create:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {
        "message":"Hello FastAPI"
    }
```

FastAPI automatically creates:

```text
/docs
```

and

```text
/redoc
```

No extra coding required.

# What Happens Internally?

Swagger acts like a client.

```text
Swagger UI
      ↓
HTTP Request
      ↓
FastAPI
      ↓
Response
      ↓
Swagger UI
```

Same Request-Response Lifecycle.

# Adding More Routes

Example:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {
        "message":"Home"
    }

@app.get("/students")
def students():
    return {
        "message":"Students"
    }

@app.get("/faculty")
def faculty():
    return {
        "message":"Faculty"
    }
```

Swagger automatically updates.

You will see:

```text
GET /
GET /students
GET /faculty
```

No manual documentation.

# Tags

Tags group APIs.

Example:

```python
@app.get(
    "/students",
    tags=["Students"]
)
def students():
    return []
```

---

```python
@app.get(
    "/faculty",
    tags=["Faculty"]
)
def faculty():
    return []
```

Swagger groups endpoints:

```text
Students
   GET /students

Faculty
   GET /faculty
```

Much cleaner.
