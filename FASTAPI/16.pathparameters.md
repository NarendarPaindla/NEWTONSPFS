# Path Parameters in FastAPI

Now we are entering one of the most important topics in API development.

Until now our routes were static.

Example:

```python
@app.get("/students")
def get_students():
    return {"message": "All Students"}
```

Whenever we call:

```http
GET /students
```

we get the same response.

But in real applications, we need dynamic data.

Example:

```text
Get Student 1
Get Student 2
Get Student 3
Get Student 100
```

Creating separate routes is impossible.

❌ Wrong

```python
@app.get("/student1")
@app.get("/student2")
@app.get("/student3")
```

Instead we use:

# Path Parameters

---

# What is a Path Parameter?

A Path Parameter is a variable value embedded directly inside the URL path.

Example:

```http
/students/1
/students/2
/students/3
```

Here:

```text
1
2
3
```

are Path Parameters.

---

# Real Life Example

Think about Instagram.

Different users have different profiles.

```text
instagram.com/ravi
instagram.com/kiran
instagram.com/suresh
```

The username part changes.

Similarly:

```http
/students/101
/students/102
/students/103
```

The ID changes.

---

# Your First Path Parameter

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/students/{student_id}")
def get_student(student_id):
    return {
        "student_id": student_id
    }
```

---

# How It Works

Request:

```http
GET /students/101
```

FastAPI extracts:

```text
student_id = 101
```

Response:

```json
{
  "student_id": "101"
}
```

# Type Hints with Path Parameters

Currently:

```python
def get_student(student_id):
```

receives string data.

Better:

```python
@app.get("/students/{student_id}")
def get_student(student_id: int):
    return {
        "student_id": student_id
    }
```

---

# Request

```http
GET /students/101
```

Response:

```json
{
  "student_id": 101
}
```

Notice:

```text
String → Integer
```

automatically converted.

---

# FastAPI Magic

If user sends:

```http
GET /students/abc
```

Expected:

```python
student_id: int
```

Received:

```text
abc
```

FastAPI automatically rejects it.

Response:

```http
422 Unprocessable Entity
```

Amazing feature.

# Path Parameter Validation

FastAPI validates automatically.

Example:

```python
@app.get("/students/{student_id}")
def get_student(student_id: int):
    return {"id": student_id}
```

---

Valid

```http
/students/10
```

Response:

```json
{
 "id":10
}
```

---

Invalid

```http
/students/abc
```

Response:

```json
{
  "detail":[
     {
       "type":"int_parsing"
     }
  ]
}
```

Status:

```http
422
```

# Common Beginner Mistakes

## Mistake 1

Wrong:

```python
@app.get("/students/student_id")
```

This is treated as text.

---

Correct:

```python
@app.get("/students/{student_id}")
```

Curly braces are mandatory.

---

## Mistake 2

Wrong:

```python
def get_student(id):
```

while route uses:

```python
{student_id}
```

Names must match.

---

Correct:

```python
@app.get("/students/{student_id}")
def get_student(student_id:int):
```

# Interview Questions

### What is a Path Parameter?

A value passed inside the URL path used to identify a specific resource.

---

### Why are Path Parameters used?

To create dynamic URLs and access specific resources.

---

### Example?

```http
/students/101
```

where:

```text
101
```

is the path parameter.

---

### Can FastAPI validate path parameters?

Yes.

Using type hints:

```python
student_id: int
```

FastAPI automatically validates and converts data.

---

### What happens if validation fails?

FastAPI returns:

```http
422 Unprocessable Entity
```

---

# Golden Rule

Use Path Parameters whenever you want to identify a specific resource.

```text
Student ID
Product ID
Order ID
User ID
Patient ID
```

Pattern:

```python
@app.get("/resource/{id}")
```

Think:

```text
Collection
      ↓
/students

Single Resource
      ↓
/students/101
```

This distinction is one of the foundations of REST API design.
