# What is WSGI?

WSGI stands for:

```text

```

It is a standard that defines communication between:

```text

```

# Synchronous vs Asynchronous

---

# Synchronous

Do one task completely.

Then start another.

```text
Task 1
   ↓
Task 2
   ↓
Task 3
```

---

# Asynchronous

Start task.

While waiting, do another task.

```text
Task 1 Waiting
      ↓
Task 2 Running
      ↓
Task 3 Running
```

Much more efficient.

---

# Restaurant Example

## Synchronous Waiter

```text

Go Kitchen
Wait
Bring Food
Take Next Order
```

Slow.

---

## Asynchronous Waiter

```text
Take Order 1

Take Order 2

```

Much faster.

# What is an Event Loop?

This is the secret behind FastAPI.

Think of it as a smart manager.

It keeps checking:

```text
Which task is waiting?
Which task is ready?
Which task can run?
```

and switches efficiently.

# FastAPI Async Example


# WSGI vs ASGI Comparison

| Feature             | WSGI                         | ASGI                                  |
| ------------------- | ---------------------------- | ------------------------------------- |
| Full Form           | Web Server Gateway Interface | Asynchronous Server Gateway Interface |
| Request Handling    | Synchronous                  | Asynchronous                          |
| Concurrent Requests | Limited                      | Excellent                             |
| WebSocket Support   | No                           | Yes                                   |
| Real-Time Apps      | Difficult                    | Excellent                             |
| Modern APIs         | Good                         | Excellent                             |
| Flask               | Yes                          | No (traditional)                      |
| Django              | Traditional WSGI             | Modern async support available        |
| FastAPI             | No                           | Yes                                   |

# Interview Questions

### What is WSGI?

A standard interface between web servers and synchronous Python web applications.

---

### What is ASGI?

A modern asynchronous interface supporting concurrent connections and real-time communication.

---

### Why is FastAPI fast?

Because it is built on ASGI and supports asynchronous request handling.

---

### What is the role of Uvicorn?

Uvicorn is an ASGI server used to run FastAPI applications.

---

### What are async and await?

Keywords used to perform non-blocking asynchronous operations.

---

### Does ASGI make every application faster?

No.

It mainly improves performance for I/O-bound operations such as database calls, API requests, file operations, and network communication.
