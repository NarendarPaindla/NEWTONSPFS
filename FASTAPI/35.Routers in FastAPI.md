# Project Structure & Routers in FastAPI (Industry-Level Architecture)

Until now we've been building everything in one file:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message":"Hello"}

@app.get("/students")
def students():
    return []

@app.post("/students")
def create_student():
    pass

@app.get("/courses")
def courses():
    pass

@app.post("/courses")
def create_course():
    pass
```

Looks fine.

But imagine after 6 months.

```text
50 Routes
20 Models
15 Services
Authentication
JWT
Database
Email
Payments
Reports
```

Your `main.py` becomes:

```text
3000+ Lines
```

Nightmare.

# Step 1: Create Router

## routers/student.py

```python
from fastapi import APIRouter

router = APIRouter()

@router.get("/")
def get_students():
    return [
        "Ravi",
        "Kiran"
    ]
```

Notice:

```python
router = APIRouter()
```

Not:

```python
app = FastAPI()
```

---

# Step 2: Register Router

## main.py

```python
from fastapi import FastAPI
from routers.student import router

app = FastAPI()

app.include_router(
    router,
    prefix="/students",
    tags=["Students"]
)
```

---

```http
GET /students/
```

# Understanding include_router

```python
app.include_router(
    router,
    prefix="/students",
    tags=["Students"]
)
```

---

## prefix

Automatically adds:

```text
/students
```

to all routes.

---

Route:

```python
@router.get("/")
```

becomes:

```http
/students
```

---

Route:

```python
@router.get("/{id}")
```

becomes:

```http
/students/{id}
```

---

# tags

Swagger grouping.

```python
tags=["Students"]
```

Swagger shows:

```text
Students
   GET /students

   POST /students
```

Very clean.

# Multiple Routers

## routers/course.py

```python
from fastapi import APIRouter

router = APIRouter()

@router.get("/")
def get_courses():
    return [
        "Python",
        "FastAPI"
    ]
```

---

## main.py

```python
from fastapi import FastAPI

from routers.student import router as student_router

from routers.course import router as course_router

app = FastAPI()

app.include_router(
    student_router,
    prefix="/students",
    tags=["Students"]
)

app.include_router(
    course_router,
    prefix="/courses",
    tags=["Courses"]
)
```

---

Now:

```http
GET /students
```

and

```http
GET /courses
```

work separately.

# Separation of Concerns

This is an interview favorite.

Every layer has one responsibility.

---

# Router Layer

Job:

```text
Receive Request
Call Service
Return Response
```

Example:

```python
@router.get("/")
def get_students():

    return student_service()
```

---

# Service Layer

Job:

```text
Business Logic
```

Example:

```python
def student_service():

    return [
        "Ravi",
        "Kiran"
    ]
```

---

# Schema Layer

Job:

```text
Validation
```

Example:

```python
class StudentCreate(BaseModel):

    name: str

    age: int
```

---

# Model Layer

Job:

```text
Database Structure
```

Example:

```python
class Student(Base):

    __tablename__ = "students"

    id = Column(Integer)

    name = Column(String)
```

# Student Module Example

---

## schemas/student.py

```python
from pydantic import BaseModel

class StudentCreate(
    BaseModel
):
    name: str
    age: int
```

---

## services/student_service.py

```python
def create_student_service(
    student
):

    return {
        "message":"Student Created",
        "student":student
    }
```

---

## routers/student.py

```python
from fastapi import APIRouter

from schemas.student import (
    StudentCreate
)

from services.student_service import (
    create_student_service
)

router = APIRouter()

@router.post("/")
def create_student(
    student: StudentCreate
):

    return create_student_service(
        student
    )
```

# Environment Variables

Hardcoding is dangerous.

Wrong:

```python
DATABASE_URL = "mongodb://localhost"
```

---

Wrong:

```python
SECRET_KEY = "abc123"
```

---

In production:

```text
Different Dev URL
Different Test URL
Different Prod URL
```

Need environment variables.

---

# .env File

```text
DATABASE_URL=mongodb://localhost:27017

SECRET_KEY=mysecretkey

DEBUG=True
```

---

# Install

```bash
pip install pydantic-settings
```

# settings.py

```python
from pydantic_settings import (
    BaseSettings
)

class Settings(
    BaseSettings
):

    DATABASE_URL: str

    SECRET_KEY: str

    DEBUG: bool

    class Config:

        env_file = ".env"

settings = Settings()
```

---

# Using Settings

```python
from configs.settings import settings

print(
    settings.DATABASE_URL
)
```

Output:

```text
mongodb://localhost:27017
```

---

# Pydantic Settings v2 Style

Modern approach:

```python
from pydantic_settings import (
    BaseSettings,
    SettingsConfigDict
)

class Settings(
    BaseSettings
):

    DATABASE_URL: str

    SECRET_KEY: str

    model_config = SettingsConfigDict(
        env_file=".env"
    )
```

---

# Database Connection Example

```python
from configs.settings import settings

```

# Interview Questions

### What is APIRouter?

Used to split routes into separate modules.

---

### Why use APIRouter?

```text
Cleaner Code
Scalable Architecture
Feature-Based Organization
```

---

### What does prefix do?

Adds a common URL prefix.

Example:

```python
prefix="/students"
```

---

### What are tags?

Used for Swagger grouping.

---

### Why separate routers/services/schemas/models?

To follow:

```text
Separation Of Concerns
```

Each layer has a single responsibility.

---

### Why use environment variables?

To avoid hardcoding secrets and configuration values.

---

### Which package loads .env in FastAPI?

```python
pydantic-settings
```

# Golden Rule

For learning:

```text
main.py
```

is okay.

For real projects:

```text
Routers
   ↓
Services
   ↓
Schemas
   ↓
Models
   ↓
Database
```

and configuration should always come from:

```text
.env
   ↓
Pydantic Settings
```

This architecture is what you'll see in professional FastAPI projects such as e-commerce systems, ERP platforms, HRMS portals, banking applications, healthcare systems, and SaaS products. 🚀
