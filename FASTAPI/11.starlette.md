# What is Starlette?

Starlette is a lightweight ASGI framework and toolkit used for building high-performance asynchronous web applications.

Simple definition:

> Starlette provides the core web functionality that FastAPI uses internally.

# Can We Use Starlette Directly?

Yes.

Example:

```python
from starlette.applications import Starlette
from starlette.responses import JSONResponse
from starlette.routing import Route

async def home(request):
    return JSONResponse({"message":"Hello"})

app = Starlette(
    routes=[
        Route("/", home)
    ]
)
```

This is pure Starlette.

---

# Same Thing in FastAPI

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {
        "message":"Hello"
    }
```

Much simpler.

That's why developers love FastAPI.
