# What is a Route?

Before writing code, understand the concept.

A Route is simply:

> A URL path that is mapped to a Python function.

Think of it as:

```text
URL
 ↓
Function
 ↓
Response
```

---

# Real Life Example

Imagine a college.

Different rooms have different purposes.

```text
Room 101 → Principal

Room 102 → Accounts

Room 103 → Library
```

Similarly:

```text
/          → Home

/students  → Student Data

/faculty   → Faculty Data
```

Each URL points to a specific function.

This mapping is called a **Route**.

# Route Registration

When FastAPI starts:

```python
@app.get("/")
def home():
```

it internally stores:

```text
Route Path = /

Method = GET

Function = home()
```

Think of FastAPI creating a table:

| Method | Path | Function |
| ------ | ---- | -------- |
| GET    | /    | home     |

---

# Multiple Routes

We can create many routes.

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {
        "message":"Home"
    }

@app.get("/students")
def students():
    return {
        "message":"Students"
    }

@app.get("/faculty")
def faculty():
    return {
        "message":"Faculty"
    }
```

---

# Internal Route Table

| Method | Path      |
| ------ | --------- |
| GET    | /         |
| GET    | /students |
| GET    | /faculty  |

# Route Naming Best Practices

Bad:

```python
@app.get("/GetStudents")
```

---

Bad:

```python
@app.get("/StudentDataList")
```

---

Good:

```python
@app.get("/students")
```

REST-friendly.

---

# Industry Standard

Resources should be nouns.

Good:

```text
/students
/users
/products
/orders
```

Avoid:

```text
/getStudents
/createStudent
/deleteStudent
```

The HTTP method already tells the action.

# Common Beginner Errors

## Missing `app`

Wrong:

```python
@app.get("/")
```

without:

```python
app = FastAPI()
```

Error.

---

## Wrong Indentation

Wrong:

```python
@app.get("/")
    def home():
```

Python error.

---

## Duplicate Routes

Wrong:

```python
@app.get("/students")
@app.get("/students")
```

Confusing behavior.

# Interview Questions

A route is a URL path mapped to a Python function that handles incoming requests.

---

### What does `@app.get("/")` mean?

When a GET request comes to `/`, execute the decorated function.

---

### What happens when a route returns a dictionary?

FastAPI automatically converts it into JSON.

---

### Can FastAPI have multiple routes?

Yes.
