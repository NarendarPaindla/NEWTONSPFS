# HTTP Protocol — The Language of the Internet

Before learning FastAPI routes, APIs, GET, POST, or databases, you must understand one thing:

> Client and Server cannot talk randomly.

They need a common language.

That language is **HTTP**.

---

# What is HTTP?

HTTP stands for:

```text
Hyper Text Transfer Protocol
```

Simple definition:

> HTTP is a set of rules that allows clients and servers to communicate with each other.

Think of HTTP as:

```text
English -> Human Communication

HTTP -> Computer Communication
```

Without HTTP:

```text
Browser ❌ Server
Mobile App ❌ Server
React App ❌ FastAPI
```

No communication would happen.

---

# Real Life Example

Imagine you go to a restaurant.

You cannot simply stare at the waiter and expect food.

You must communicate.

Example:

```text
Customer:
One Chicken Biryani please

Waiter:
Okay
```

Communication happened.

Similarly:

```text
Browser:
Give me students data

Server:
Here is the data
```

HTTP defines how this conversation should happen.

---

# Why HTTP Was Created?

Suppose a browser sends:

```text
Give me data
```

Server may ask:

```text
Which data?
```

Different companies could invent different formats.

Chaos!

So HTTP created standard rules.

Now every browser and server understand each other.

# HTTP is Stateless

One of the most important interview concepts.

---

## What is Stateless?

Server does NOT remember previous requests.

Example:

Request 1

```http
GET /profile
```

Server responds.

Request finished.

---

Later:

Request 2

```http
GET /orders
```

Server treats it like a completely new request.

It does not automatically remember you.

# HTTP Status Codes

Server responds with numbers.

These numbers tell what happened.

---

# 200 OK

Meaning:

```text
Everything successful
```

Example:

```http
200 OK
```

---

# 201 Created

Meaning:

```text
New resource created
```

Example:

Student created.

```http
201 Created
```

---

# 400 Bad Request

Meaning:

```text
Client sent invalid data
```

Example:

```json
{
  "age":-10
}
```

Validation fails.

---

# 401 Unauthorized

Meaning:

```text
Login Required
```

Example:

Accessing profile without login.

---

# 403 Forbidden

Meaning:

```text
Permission denied
```

Example:

Normal user trying to delete all users.

---

# 404 Not Found

Most famous status code.

Example:

```http
GET /abcxyz
```

Route doesn't exist.

Response:

```http
404 Not Found
```

---

# 500 Internal Server Error

Meaning:

Something broke on server.

Example:

Database crashed.

Bug in code.

---

# Status Code Categories

```text
5xx -> Server Error
```

# What FastAPI Does Internally

When FastAPI receives:

```http
GET /students
```

It:

```text
Receive Request
      ↓
Match Route
      ↓
Execute Function
      ↓
Generate JSON
      ↓
Send Response
```

Example:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/students")
def get_students():
    return [
        {"id":1,"name":"Ravi"}
    ]
```

Client sends:

```http
GET /students
```

Server responds:

```json
[
 {
   "id":1,
   "name":"Ravi"
 }
]
```

```text

   ↓

   ↓

   ↓
```
