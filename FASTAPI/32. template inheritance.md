# Template Inheritance in Jinja2 (One of the Most Important Features)

Imagine you are building a college website.

Pages:

```text
Home Page
About Page
Courses Page
Contact Page
Dashboard Page
```

Every page has:

```text
Header
Navigation Bar
Footer
```

Without Template Inheritance:

### about.html

# Step 1: Create base.html

This contains common layout.

```html
<!DOCTYPE html>
<html>

<head>
    <title>{% block title %}
        My Website
    {% endblock %}
    </title>
</head>

<body>

    <header>
        <h1>Newton School</h1>
    </header>

    <nav>
        Home |
        About |
        Contact
    </nav>

    <hr>

    {% block content %}

    {% endblock %}

    <hr>

    <footer>
        Copyright 2026
    </footer>

</body>
</html>
```

---

# Understanding block

```html
{% block content %}

{% endblock %}
```

Think:

```text
Placeholder
```

Visual:

```text

Navbar
```

# Step 2: Create home.html

```html

{% endblock %}
```

# FastAPI Route

```python
from fastapi import FastAPI, Request
from fastapi.templating import Jinja2Templates

app = FastAPI()

templates = Jinja2Templates(
    directory="templates"
)

@app.get("/")
def home(request: Request):

    return templates.TemplateResponse(
        request=request,
        name="home.html"
    )


@app.get("/about")
def about(request: Request):

    return templates.TemplateResponse(
        request=request,
        name="about.html"
    )
```

# Interview Questions

### What is Template Inheritance?

A mechanism where child templates inherit layout from a parent template.

---

### Which keyword is used?

```html
{% extends "base.html" %}
```

---

### What is a block?

A placeholder that child templates can override.

Example:

```html
{% block content %}
{% endblock %}
```

---

### What is include used for?

To reuse small template components.

```html
{% include "navbar.html" %}
```

# Golden Rule

```text
Repeated Layout
        ↓
Put In base.html

Changing Content
        ↓
Put In Child Templates

Small Reusable Parts
        ↓
Use include
```

This is exactly how professional FastAPI, Flask, and Django applications build dashboards, admin panels, ERP systems, reporting portals, and internal company tools. 🚀
