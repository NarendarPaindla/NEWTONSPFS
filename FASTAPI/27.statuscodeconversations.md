# HTTP Status Code Conventions in FastAPI

One of the biggest mistakes beginners make is:

```python
return {
    "message": "Student Not Found"
}
```

and still returning:

```http
200 OK
```

This is wrong.

In professional APIs:

> The **status code** tells the client what happened before it even reads the JSON response.

---

# Why Status Codes Matter?

Imagine ordering food on Swiggy.

The delivery app says:

```text
Order Delivered
```

or

```text
Restaurant Closed
```

or

```text
Payment Failed
```

These are statuses.

HTTP Status Codes do the same thing for APIs.

---

# Status Code Categories

## 1xx → Informational

Rarely used in API development.

```http
100 Continue
```

---

## 2xx → Success

Request succeeded.

Most common category.

---

## 3xx → Redirection

Resource moved somewhere else.

Mostly used by browsers.

---

## 4xx → Client Error

Client made a mistake.

Examples:

```text
Wrong Input
Missing Token
Invalid Request
```

---

## 5xx → Server Error

Server failed.

Examples:

```text
Database Down
Code Crash
Internal Error
```

---

# Most Important Status Codes for FastAPI

You only need these daily:

```text
200 OK
201 Created
204 No Content

400 Bad Request
401 Unauthorized
403 Forbidden
404 Not Found
422 Unprocessable Entity

500 Internal Server Error
```

---

# 200 OK

## Meaning

```text
Request Successful
```

Most GET APIs return this.

---

Example

```python
@app.get("/students")
def get_students():

    return {
        "students": []
    }
```

---

Response

```http
200 OK
```

```json
{
  "students":[]
}
```

---

# Real Life Example

Student exists.

```http
GET /students/101
```

Response:

```http
200 OK
```

---

# 201 Created

## Meaning

```text
New Resource Created
```

Used for:

```text
POST APIs
```

---

Example

```python
from fastapi import status

@app.post(
    "/students",
    status_code=status.HTTP_201_CREATED
)
def create_student(student: dict):

    return {
        "message":"Student Created"
    }
```

---

Response

```http
201 Created
```

---

# Real Industry Example

```http
POST /register
```

New user created.

Return:

```http
201 Created
```

Not:

```http
200 OK
```

---

# 204 No Content

## Meaning

```text
Success
But No Response Body
```

Common for DELETE APIs.

---

Example

```python
from fastapi import Response

@app.delete("/students/{id}")
def delete_student(id: int):

    return Response(
        status_code=204
    )
```

---

Response

```http
204 No Content
```

No JSON returned.

---

# 400 Bad Request

## Meaning

```text
Client Sent Invalid Request
```

---

Example

```python
raise HTTPException(
    status_code=400,
    detail="Age Cannot Be Negative"
)
```

---

Response

```http
400 Bad Request
```

```json
{
  "detail":"Age Cannot Be Negative"
}
```

---

# Real Example

```json
{
  "age": -5
}
```

Invalid business rule.

# 401 Unauthorized

## Meaning

```text
Authentication Required
```

User not logged in.

---

Example

```python
raise HTTPException(
    status_code=401,
    detail="Please Login"
)
```

---

Response

```http
401 Unauthorized
```

---

# Real Example

Trying to access:

```http
GET /profile
```

without token.

---

# 403 Forbidden

## Meaning

```text
Authenticated
But Not Allowed
```

---

Example

User logged in.

But trying to access:

```http
GET /admin
```

---

Response

```http
403 Forbidden
```

---

Example

```python
raise HTTPException(
    status_code=403,
    detail="Access Denied"
)
```

---

# Difference Between 401 and 403

Students confuse this often.

---

## 401

```text
Who Are You?
```

Not authenticated.

---

## 403

```text
I Know Who You Are
But You Can't Enter
```

Authenticated but unauthorized.

---

Real Example:

```text
No ID Card
   ↓
401

Valid ID Card
But Staff Room Access
   ↓
403
```

---

# 404 Not Found

## Meaning

```text
Resource Does Not Exist
```

Most common error.

---

Example

```python
raise HTTPException(
    status_code=404,
    detail="Student Not Found"
)
```

---

Request

```http
GET /students/999
```

---

Response

```http
404 Not Found
```

```json
{
  "detail":"Student Not Found"
}
```

---

# 422 Unprocessable Entity

## Meaning

Validation Failed.

FastAPI uses this automatically.

---

Example

```python
@app.get("/students/{student_id}")
def get_student(student_id: int):
    return {}
```

---

Request

```http
GET /students/abc
```

---

FastAPI Response

```http
422 Unprocessable Entity
```

---

Because:

```text
abc
```

cannot become:

```python
int
```

---

# Why FastAPI Uses 422

Validation passed:

```text
Request Structure Valid
```

But:

```text
Data Invalid
```

Example:

```text
Expected int
Received string
```

---

# 500 Internal Server Error

## Meaning

Server crashed.

Usually indicates a bug.

---

Example

```python
@app.get("/")
def home():

    x = 10 / 0

    return x
```

---

Response

```http
500 Internal Server Error
```

```text
    ↓

    ↓

```

# Golden Rule

Whenever you build an API, ask:

```text
What Actually Happened?
```

Then return the appropriate status code.

A professional API is not judged only by its JSON response—it is also judged by whether it returns the correct HTTP status codes. This is something every frontend developer, mobile developer, and backend interviewer expects you to understand. 🚀
