# Pydantic Fundamentals

Until now we've been writing:

```python
@app.post("/students")
def create_student(student: dict):
    return student
```

Looks okay.

But there is a huge problem.

---

# Problem with dict

Suppose client sends:

```json
{
  "name":"Ravi",
  "age":"twenty one"
}
```

FastAPI accepts it.

---

Suppose client sends:

```json
{
  "xyz":"abc"
}
```

FastAPI accepts it.

---

Suppose client sends:

```json
{
  "age":21
}
```

FastAPI accepts it.

---

Why?

Because:

```python
student: dict
```

means:

```text
Accept Any JSON
```

No validation.

No structure.

No type checking.

Dangerous in production.

---

# Pydantic

# What is Pydantic?

Pydantic is a data validation library.

Think:

```text
JSON
  ↓
Validation
  ↓
Python Object
```

It verifies:

```text
Required Fields
Data Types
Rules
Constraints
```

before your route executes.

---

# Pydantic v2

FastAPI now uses:

```text
Pydantic v2
```

which is:

```text
Faster
Cleaner
Better Validation
```

than Pydantic v1.

# Field()

# Basic Field Example

```python
from pydantic import BaseModel, Field

class Student(BaseModel):

    name: str = Field(
        min_length=3,
        max_length=50
    )

    age: int = Field(
        gt=0
    )
```

---

Meaning:

```text
Name Length:
3 - 50

Age:
Greater Than 0
```

# Annotated (Pydantic v2 Style)

Modern Pydantic prefers:

```python
from typing import Annotated
from pydantic import Field
```

---

Example

```python
from typing import Annotated

NameType = Annotated[
    str,
    Field(
        min_length=3,
        max_length=50
    )
]
```

---

Use:

```python
class Student(BaseModel):

    name: NameType

    age: int
```

---

Another Example

```python
from typing import Annotated
from pydantic import BaseModel, Field

class Student(BaseModel):

    name: Annotated[
        str,
        Field(
            min_length=3,
            max_length=50
        )
    ]

    age: Annotated[
        int,
        Field(
            ge=18,
            le=60
        )
    ]
```

---

This is the recommended modern approach.

# Response Models

Pydantic is not only for requests.

It can also validate responses.

---

Example

```python
class StudentResponse(BaseModel):
    id: int
    name: str
```

---

Route:

```python
@app.get(
    "/students/{id}",
    response_model=StudentResponse
)
def get_student(id: int):

    return {
        "id": id,
        "name": "Ravi"
    }
```

---

FastAPI validates output.

Very useful in production.
