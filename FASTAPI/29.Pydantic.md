# Pydantic v2 Validator

```python
from pydantic import (
    BaseModel,
    field_validator
)

class Student(BaseModel):

    age: int

    @field_validator("age")
    @classmethod
    def validate_age(cls, value):

        if value < 18:
            raise ValueError(
                "Age must be at least 18"
            )

        return value
```

# Multiple Validators

```python
class Student(BaseModel):

    age: int

    @field_validator("age")
    @classmethod

            raise ValueError(
                "Age too large"
            )

        return value
```
