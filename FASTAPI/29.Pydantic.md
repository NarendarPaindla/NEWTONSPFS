# What is Pydantic?

Pydantic is a data validation library.

Think:

```text
JSON
  ↓
Validation
  ↓
Python Object
```

It verifies:

```text
Required Fields
Data Types
Rules
Constraints
```

before your route executes.

# Annotated (Pydantic v2 Style)

Modern Pydantic prefers:

```python
from typing import Annotated
from pydantic import Field
```

---

Example

```python
from typing import Annotated

NameType = Annotated[
    str,
    Field(
        min_length=3,
        max_length=50
    )
]
```

---

Use:

```python
class Student(BaseModel):

    name: NameType

    age: int
```

---

Another Example

```python
from typing import Annotated
from pydantic import BaseModel, Field

class Student(BaseModel):

    name: Annotated[
        str,
        Field(
            min_length=3,
            max_length=50
        )
    ]

    age: Annotated[
        int,
        Field(
            ge=18,
            le=60
        )
    ]
```

This is the recommended modern approach.

# Custom Validators

Sometimes built-in validation is not enough.

Example:


# Pydantic v2 Validator

```python
from pydantic import (
    BaseModel,
    field_validator
)

class Student(BaseModel):

    age: int

    @field_validator("age")
    @classmethod
    def validate_age(cls, value):

        if value < 18:
            raise ValueError(
                "Age must be at least 18"
            )

        return value
```

# Multiple Validators

```python
class Student(BaseModel):

    age: int

    @field_validator("age")
    @classmethod
    def validate_age(cls, value):

        if value < 18:
            raise ValueError(
                "Age must be at least 18"
            )

        if value > 60:
            raise ValueError(
                "Age too large"
            )

        return value
```


With:

Very useful.
