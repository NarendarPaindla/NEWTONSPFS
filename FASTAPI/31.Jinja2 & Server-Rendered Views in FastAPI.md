# Jinja2 & Server-Rendered Views in FastAPI

Until now we have built APIs that return:

```json
{
  "message":"Hello"
}
```

But before React, Angular, and Vue became popular, backend frameworks used to generate HTML pages directly.

This is called:

# Server-Side Rendering (SSR)

```text
Browser
   ↓
Request
   ↓
FastAPI
   ↓
HTML Generated
   ↓
Browser
```

Instead of:

```text
Browser
   ↓
React
   ↓
API
   ↓
JSON
```

---

# What is Jinja2?

Jinja2 is a Template Engine.

Think:

```text
Python Variables
      +
HTML
      ↓
Dynamic HTML Page
```

Example:

Template:

```html
<h1>Hello {{ name }}</h1>
```

Python:

```python
name = "Ravi"
```

Output:

```html
<h1>Hello Ravi</h1>
```

# Setup Jinja2 in FastAPI

```python
from fastapi import FastAPI, Request
from fastapi.templating import Jinja2Templates

app = FastAPI()

templates = Jinja2Templates(
    directory="templates"
)
```

---

# First Server Rendered Route

```python
from fastapi import FastAPI, Request
from fastapi.templating import Jinja2Templates

app = FastAPI()

templates = Jinja2Templates(
    directory="templates"
)

@app.get("/")
def home(request: Request):

    return templates.TemplateResponse(
        request=request,
        name="home.html",
        context={
            "name":"Ravi"
        }
    )
```

# Rendering Lists

Real Example:

Student List.

Route:

```python
@app.get("/students")
def students(request: Request):

    data = [
        "Ravi",
        "Kiran",
        "Rahul"
    ]

    return templates.TemplateResponse(
        request=request,
        name="students.html",
        context={
            "students":data
        }
    )
```

---

Template:

```html
<h1>Students</h1>

<ul>

{% for student in students %}

<li>{{ student }}</li>

{% endfor %}

</ul>
```

---

Output:

```html
Students

• Ravi
• Kiran
• Rahul
```

# Building a Student Table

Route:

```python
@app.get("/students")
def students(request: Request):

    data = [
        {
            "id":1,
            "name":"Ravi"
        },
        {
            "id":2,
            "name":"Kiran"
        }
    ]

    return templates.TemplateResponse(
        request=request,
        name="students.html",
        context={
            "students":data
        }
    )
```

---

Template:

```html
<table border="1">

<tr>
    <th>ID</th>
    <th>Name</th>
</tr>

{% for student in students %}

<tr>
    <td>{{ student.id }}</td>
    <td>{{ student.name }}</td>
</tr>

{% endfor %}

</table>
```

---

Output

```text
+----+--------+
| ID | Name   |
+----+--------+
| 1  | Ravi   |
| 2  | Kiran  |
+----+--------+
```

# API vs Jinja Rendering

## API

```python
@app.get("/students")
def students():

    return {
        "students":[]
    }
```

Response:

```json
{
  "students":[]
}
```

---

## Jinja

```python
@app.get("/students")
def students():

    return templates.TemplateResponse(...)
```

Response:

```html
<html>
...
</html>
```

# When Not To Use Jinja2?

Modern frontend:

```text
React
Angular
Vue
Flutter
React Native
```

Usually consume JSON APIs.

In such cases:

```text
FastAPI
      ↓
JSON API
      ↓
React
```

No Jinja.

# Golden Rule

```text
JSON Needed?
      ↓
Use FastAPI API Routes

HTML Needed?
      ↓
Use Jinja2 Templates
```

Jinja2 allows FastAPI to behave like Django or Flask by rendering dynamic HTML pages directly from the server. It is still heavily used for admin dashboards, reporting systems, ERP applications, and internal enterprise tools. 🚀
