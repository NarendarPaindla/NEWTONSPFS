# Step 3: Create Virtual Environment

---

# What Problem Does Virtual Environment Solve?

Imagine:

Project A uses:

```text
FastAPI 0.110
```

Project B uses:

```text
FastAPI 0.120
```

Without isolation:

```text
Version Conflicts
```

occur.

---

# Solution

Virtual Environment

Each project gets its own dependencies.

---

# Create Virtual Environment

Inside project:

```bash
python -m venv venv
```

This creates:

```text
fastapi-learning/
│
├── venv/
```

---

# What is Inside venv?

```text
Python Interpreter
Libraries
Packages
Scripts
```

Project-specific environment.

---

## Windows

```bash

```

---

## Mac/Linux


---


# Why Companies Use Virtual Environments

# Our First FastAPI Program

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {
        "message": "Hello FastAPI"
    }
```

---

# Understanding Line by Line

---

## Import FastAPI

```python
from fastapi import FastAPI
```

Bring FastAPI class into program.

---

## Create Application Object

```python
app = FastAPI()
```

Think:

```text
Create Backend Application
```

Everything revolves around this object.

---

## Route

```python
@app.get("/")
```

Meaning:

```text
When someone visits "/"
execute below function
```

---

## Function

```python
def home():
```

Business logic starts here.

---

## Response

```python
return {
    "message":"Hello FastAPI"
}
```

FastAPI converts dictionary into JSON.

---

# Step 7: Run FastAPI

Open terminal.

Execute:

```bash
uvicorn main:app --reload
```

---

# Understanding This Command

---

## uvicorn

ASGI Server

---

## main

Filename

```text
main.py
```

without extension.

---

## app

Application object

```python
app = FastAPI()
```

---

## --reload

Auto restart when code changes.

Perfect for development.

---

# What Happens Internally?

Command:

```bash
uvicorn main:app --reload
```

Process:

```text
Uvicorn Starts
      ↓
Loads main.py
      ↓
Finds app
      ↓
Creates Server
      ↓
Waits For Requests
```

---

# Successful Output

You see:

```text

http://127.0.0.1:8000
```

Congratulations 🎉

# First Request

Open browser:

```text
http://127.0.0.1:8000
```

Browser sends:

```http
GET /
```

FastAPI receives request.

Response:

```json
{
  "message":"Hello FastAPI"
}
```

---

# Request Lifecycle Here

```text
Browser
   |
GET /
   |
   V
Uvicorn
   |
   V
FastAPI
   |
home()
   |
return JSON
   |
   V
Browser
```

This is the same Request-Response Lifecycle we learned earlier.

# Hands-On Exercise

Create:


```bash
uvicorn main:app --reload
```


```json
{
```
