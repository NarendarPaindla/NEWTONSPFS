# GET, POST, PUT, PATCH, DELETE Semantics in FastAPI

This is one of the most important REST API topics.

Many beginners know:

```python
@app.get()

@app.post()

@app.put()

@app.patch()

@app.delete()
```

But they don't know:

> Why do we have different HTTP methods if all of them can send and receive data?

The answer is:

# Semantics

Semantics means:

> The intended meaning of the operation.

Think of traffic signals.

```text
🟢 Green  = Go

🟡 Yellow = Be Careful

🔴 Red    = Stop
```

Technically, you could ignore them.

But everyone follows the meaning.

Similarly:

```text
GET    = Read Data

POST   = Create Data

PUT    = Replace Data

PATCH  = Update Partially

DELETE = Remove Data
```

---

# Real Industry Example

Student Management System

Database:

```json
{
  "id": 101,
  "name": "Ravi",
  "age": 21,
  "department": "CSE"
}
```

Let's see how each HTTP method works.

---

# 1. GET

## Meaning

```text
Retrieve Data
Read Data
Fetch Data
```

GET should not change anything.

---

# Real Life Example

Open Instagram.

```text
View Profile
View Posts
View Followers
```

You are only reading data.

---

# FastAPI Example

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/students")
def get_students():
    return [
        {
            "id": 101,
            "name": "Ravi"
        }
    ]
```

---

Request

```http
GET /students
```

Response

```json
[
  {
    "id":101,
    "name":"Ravi"
  }
]
```

---

# Important Rule

GET should:

✅ Fetch data

❌ Create data

❌ Delete data

❌ Update data

---

# Industry Examples

```http
GET /students

GET /products

GET /orders

GET /users/101
```

# 2. POST

## Meaning

```text
Create New Resource
```

POST is used when creating something.

---

# Real Life Example

Student Registration Form.

User enters:

```json
{
  "name":"Ravi",
  "age":21
}
```

Clicks:

```text
Submit
```

New student created.

---

# FastAPI Example

```python
from fastapi import FastAPI

app = FastAPI()

@app.post("/students")
def create_student(student: dict):
    return {
        "message": "Student Created",
        "student": student
    }
```

---

Request

```http
POST /students
```

Body

```json
{
  "name":"Ravi",
  "age":21
}
```

---

Response

```json
{
  "message":"Student Created",
  "student":{
      "name":"Ravi",
      "age":21
  }
}
```

---

# Industry Examples

```http
POST /students

POST /products

POST /orders

POST /register
```

# 3. PUT

## Meaning

```text
Replace Entire Resource
```

This is where many students get confused.

PUT means:

> Replace the existing object with a new version.

---

Current Student

```json
{
  "id":101,
  "name":"Ravi",
  "age":21,
  "department":"CSE"
}
```

---

PUT Request

```json
{
  "name":"Rahul",
  "age":22,
  "department":"ECE"
}
```

---

Result

```json
{
  "id":101,
  "name":"Rahul",
  "age":22,
  "department":"ECE"
}
```

Entire object replaced.

---

# FastAPI Example

```python
@app.put("/students/{student_id}")
def update_student(
    student_id: int,
    student: dict
):
    return {
        "id": student_id,
        "updated_data": student
    }
```

---

Request

```http
PUT /students/101
```

Body

```json
{
  "name":"Rahul",
  "age":22,
  "department":"ECE"
}
```

---

# Real Life Example

Replacing an old resume with a completely new resume.

Old version gone.

New version replaces it.

---

# 4. PATCH

## Meaning

```text
Partial Update
```

Only update fields that changed.

---

Current Student

```json
{
  "id":101,
  "name":"Ravi",
  "age":21,
  "department":"CSE"
}
```

---

PATCH Request

```json
{
  "age":22
}
```

---

Result

```json
{
  "id":101,
  "name":"Ravi",
  "age":22,
  "department":"CSE"
}
```

Only age changed.

---

# FastAPI Example

```python
@app.patch("/students/{student_id}")
def patch_student(
    student_id: int,
    data: dict
):
    return {
        "id": student_id,
        "patched_data": data
    }
```

---

Request

```http
PATCH /students/101
```

Body

```json
{
  "age":22
}
```

---

Response

```json
{
  "id":101,
  "patched_data":{
      "age":22
  }
}
```
