# What Is A Media Query?

Media Query allows CSS to ask:

```text
"How big is the screen?"
```

Then apply different styles.

---

Think:

```text
IF Screen Is Small

Do This

ELSE

Do Something Else
```

---

# Memory Trick

Media Query = Security Guard

Asks:

```text
How big is your screen?
```

Then decides entry rules.

---

# Syntax

```css
@media()
{
 CSS Rules
}
```

---

Example

```css
@media
(
 max-width:768px
)
{
 h1
 {
   color:red;
 }
}
```

Meaning:

```text
If screen ≤ 768px

Make heading red
```
