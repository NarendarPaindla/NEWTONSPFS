# PROPERTY 1

# font-family

---

# What is Font?

Font is the design style of text.

Example:

```text
WELCOME

WELCOME

WELCOME
```

Same word.

Different appearance.

---

# Real Life Example

Think of handwriting.

Every person writes differently.

Same letters.

Different style.

Fonts work similarly.

---

# Syntax

```css
font-family:Arial;
```

---

# Activity

```html
<h1>Welcome To CSS</h1>
```

```css
h1
{
 font-family:Arial;
}
```

Observe the text.

---

# Change Font

```css
font-family:Verdana;
```

---

```css
font-family:Georgia;
```

---

```css
font-family:Tahoma;
```

Observe differences.

---

# Common Fonts

```text
Arial
Verdana
Tahoma
Times New Roman
Georgia
Courier New
Trebuchet MS
```

---

# Memory Trick

```text
Font Family

=

Surname of Text
```

Just like:

```text
Reddy Family

Sharma Family

Khan Family
```

Text also belongs to a family.

---

# Font Fallback

Professional developers write:

```css
font-family:Arial, Helvetica, sans-serif;
```

---

Why?

Suppose Arial unavailable.

Browser tries:

```text
Helvetica
```

Still unavailable?

Browser uses:

```text
sans-serif
```

---

# Memory Story

Imagine:

```text
Bus 1 missed

Take Bus 2

Bus 2 missed

Take Bus 3
```

Fallback fonts work exactly like that.

# PROPERTY 5

# line-height

This is where websites become readable.

---

# Problem

Without line-height.

```text
Line 1
Line 2
Line 3
Line 4
```

Everything feels crowded.

---

# Solution

```css
line-height:2;
```

---

Visual

```text
Line 1

Line 2

Line 3

Line 4
```

Much easier to read.

---

# Memory Trick

Line Height

=

Distance between floors in a building.

---

# Activity

```html
<p>
Lorem ipsum dolor sit amet
consectetur adipisicing elit.
</p>
```

```css
p
{
 line-height:2;
}
```

Observe readability improvement.

---

# Professional Rule

For paragraphs:

```css
line-height:1.5;
```

or

```css
line-height:1.8;
```

Used almost everywhere.
