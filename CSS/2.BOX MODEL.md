

❌ Overflow problems

❌ Spacing confusion

```html

</div>
```

# A Mystery Every CSS Student Faces

Ask students:

```css
.box
{
    width:300px;
    padding:20px;
    border:5px solid black;
}
```

Question:

### What is the width?

Most students answer:

```text
300px
```

Browser says:

```text
No.
```

Actual width becomes:

```text
300
+20
+20
+5
+5
----
350px
```

This surprises every beginner.

---

# Why Does This Happen?

Because browsers use:

```css
box-sizing:content-box;
```

by default.

---

# CONTENT BOX

Imagine:

```text
width = content only
```

Visual:

```text
┌──────────────────────────┐
│ Border                   │
│ ┌──────────────────────┐ │
│ │ Padding              │ │
│ │ ┌──────────────────┐ │ │
│ │ │ 300px Content    │ │ │
│ │ └──────────────────┘ │ │
│ └──────────────────────┘ │
└──────────────────────────┘
```

Width applies ONLY to content.

Not padding.

Not border.

---

# Real Calculation

```css
.box
{
 width:300px;
 padding:20px;
 border:5px solid;
}
```

Actual Width:

```text
300
+20
+20
+5
+5

=350px
```

---

# Memory Trick

Content Box means:

> Width only cares about content.

Nothing else.

---

# PROFESSIONAL SOLUTION

```css
box-sizing:border-box;
```

---

# What Does It Do?

Now width includes:

```text
Content
Padding
Border
```

inside itself.

---

Example

```css
.box
{
 width:300px;

 padding:20px;

 border:5px solid black;

 box-sizing:border-box;
}
```

Now actual width remains:

```text
300px
```

Not 350.

Exactly 300.

---

# Visual

Before

```text
300 + padding + border
```

After

```text
300 includes everything
```

---

# Memory Trick

Imagine Pizza.

Content Box

```text
Pizza = 300

Box extra
Cover extra
```

Size increases.

---

Border Box

```text
Whole package = 300
```

Everything included.

---

# Why Every Professional Uses This

Because:

```css
*
{
    box-sizing:border-box;
}
```

makes sizing predictable.

No surprises.

No broken layouts.
