# CSS MASTERCLASS – TOPIC 1: CSS SELECTORS

### Teach This Like a Story, Not Like Syntax

Before students learn colors, layouts, animations, or responsive design, they must understand one thing:

> **How does CSS know WHICH element to style?**

That answer is:

# CSS SELECTORS

---

# Real Life Analogy

Imagine you are a teacher in a classroom with 100 students.

How do you call a student?

### Method 1

"Hey Student"

Everybody looks.

Similar to:

```html
p
{
 color:red;
}
```

All paragraphs get selected.

---

### Method 2

"Hey Roll No 25"

Only one student responds.

Similar to:

```html
#header
{
 color:red;
}
```

ID Selector.

---

### Method 3

"Hey Front Bench Students"

Only a group responds.

Similar to:

```html
.highlight
{
 color:red;
}
```

Class Selector.

# Structure of CSS Rule

```css
selector
{
 property:value;
}
```

Example

```css
h1
{
 color:blue;
}
```

Breakdown

```css
h1
```

Selector

```css
color
```

Property

```css
blue
```

Value

# Why Selectors Matter

Without selectors:

```css
{
 color:red;
}
```

Browser asks:

"Whom should I style?"

No answer.

No styling.

Selectors tell CSS:

> "Apply styles to THESE elements."

---

# CSS Selector Family Tree

There are many selectors.

Think of them as levels.

---

# Level 1 Selectors

1. Universal Selector
2. Element Selector
3. ID Selector
4. Class Selector

These four alone can build most websites.

Master them first.

---

# 1. Universal Selector (*)

Selects EVERYTHING.

Syntax

```css
*
{
 color:red;
}
```

Meaning:

Style every element.

---

## Activity

```html
<!DOCTYPE html>
<html>
<head>
<style>

*
{
 color:red;
}

</style>
</head>
<body>

<h1>Heading</h1>
<p>Paragraph</p>
<button>Click</button>

</body>
</html>
```

Everything becomes red.

---

# Memory Trick

```css
*
```

Looks like a star.

Star shines everywhere.

Universal selector affects everything.

---

# Practical Use

Reset styles.

```css
*
{
 margin:0;
 padding:0;
 box-sizing:border-box;
}
```

Almost every modern website starts like this.

---

# Mini Project

Without Universal Selector

```html
<h1>Title</h1>
<p>Text</p>
```

Browser adds default margins.

With:

```css
*
{
 margin:0;
}
```

Everything starts clean.

# 3. ID Selector

Most Important Rule:

### ID MUST BE UNIQUE

One page

One element

One ID

---

HTML

```html
<h1 id="logo">
VillageBasket
</h1>
```

CSS

```css
#logo
{
 color:red;
}
```

---

# Why # ?

Because CSS uses:

```css
#
```

for IDs.

---

# Memory Trick

Think:

ID Card

Everyone has a unique ID.

Same in HTML.

---

## Activity

```html
<!DOCTYPE html>
<html>
<head>

<style>

#mainHeading
{
 color:blue;
}

</style>

</head>
<body>

<h1 id="mainHeading">
Welcome
</h1>

<h1>
Hello
</h1>

</body>
</html>
```

Only first heading becomes blue.

---

# Wrong Practice

```html
<h1 id="title">A</h1>

<h1 id="title">B</h1>
```

Avoid.

Duplicate IDs create problems.

---

# ID vs Class

Students always get confused.

Use this table while teaching.

| Feature  | ID          | Class             |
| -------- | ----------- | ----------------- |
| Symbol   | #           | .                 |
| Unique   | Yes         | No                |
| Reusable | No          | Yes               |
| Used For | One Element | Multiple Elements |
| Example  | #header     | .btn              |

---

# GOLDEN RULE

### IDs identify.

### Classes classify.

Remember this forever.
