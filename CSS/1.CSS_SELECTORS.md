# 1. Universal Selector (*)

Selects EVERYTHING.

Syntax

```css
*
{
 color:red;
}
```

Meaning:

Style every element.

---

## Activity

```html
<!DOCTYPE html>
<html>
<head>
<style>

*
{
 color:red;
}

</style>
</head>
<body>

<h1>Heading</h1>
<p>Paragraph</p>
<button>Click</button>

</body>
</html>
```

Everything becomes red.

---

# Memory Trick

```css
*
```

Looks like a star.

Star shines everywhere.

Universal selector affects everything.

---

# Practical Use

Reset styles.

```css

{
 margin:0;
 padding:0;
 box-sizing:border-box;
}
```

Almost every modern website starts like this.

# 1. GROUPING SELECTOR

---

## Problem

Suppose you want:

```css
h1
{
 color:red;
}

h2
{
 color:red;
}

p
{
 color:red;
}
```

Same code repeated.

Bad practice.

---

## Solution

Grouping Selector

```css
h1,h2,p
{
 color:red;
}
```

---

# Memory Trick

Comma means:

> "Apply to ALL of these."

Think:

```text
Ramesh, Suresh, Mahesh
```

Calling three people at once.

Same in CSS.

</body>
</html>
```

Everything becomes blue.

---

# Professional Example

{
 font-family:Arial;
}
```

Very common.

# 3. CHILD SELECTOR (>)

Students confuse this with Descendant Selector.

This is very important.

---

# Descendant

```css
div p
```

Selects all descendants.

Could be child.

Could be grandchild.

Could be great-grandchild.

---

# Child Selector

```css
div > p
```

Selects ONLY direct children.

---

# Family Analogy

Imagine:

```text
Grandfather
    Father
         Son
```

Descendant:

Everyone below.

Child:

Only immediate child.

---

# Example

HTML

```html
<div>

<p>Paragraph 1</p>

<section>

<p>Paragraph 2</p>

</section>

</div>
```

CSS

```css
div > p
{
 color:red;
}
```

---

# Selected

```html
<p>Paragraph 1</p>
```

---

# Not Selected

```html
<section>

<p>Paragraph 2</p>

</section>
```

Because it's a grandchild.

---

# Visual Memory

```text
div
├── p ✔
└── section
      └── p ❌
```

---

# Professional Example

```css
ul > li
{
 list-style:none;
}
```

Used often in navigation menus.

---

# Memory Trick

```css
>
```

Arrow means:

"Direct child only."

---

# Descendant vs Child

```css
div p
```

ALL p inside div.

---

```css
div > p
```

Only direct p children.

---

# Activity

Create both selectors.

Observe difference.

Students remember forever after seeing output.

# 5. GENERAL SIBLING SELECTOR (~)

{

---

# Visual

```text

p ✔

p ✔
```

---

# Difference

Adjacent

```css

```

Only first p.

---

General

```css

```

All p after h1.

---

# Memory Trick

```css
~
```

Think:

Wave spreads everywhere.

So style spreads to all following siblings.

# PSEUDO ELEMENTS

Pseudo Classes select STATES.

Pseudo Elements select PARTS of an element.

---

Pseudo Element uses:

```css
::
```

Double colon.

---

# Memory Trick

```text
:
```

State

```text
::
```

Part

# ::first-letter

HTML

```html
<p>
Welcome To CSS
</p>
```

CSS

```css
p::first-letter
{
 font-size:50px;
 color:red;
}
```

Only W becomes large.

---

Used in magazines and blogs.

---

# Visual

Before

```text
Welcome To CSS
```

After

```text
Welcome To CSS
↑
Large Red W
```

---

# ::first-line

```css
p::first-line
{
 color:red;
}
```

Styles first line only.

---

# ::selection

Most students love this.

---

CSS

```css
::selection
{
 background:black;
 color:white;
}
```

When text is selected.

Custom colors appear.

---

Try this in browser.

Students remember forever.

---

# ::before

Creates content before element.

HTML

```html
<p>
CSS
</p>
```

CSS

```css
p::before
{
 content:"🔥 ";
}
```

Output

```text
🔥 CSS
```

---

# ::after

```css
p::after
{
 content:" 🚀";
}
```

Output

```text
CSS 🚀
```

---

# Professional Example

```css
.required::after
{
 content:" *";
 color:red;
}
```

HTML

```html
<label class="required">
Email
</label>
```

Output

```text
Email *
```
