---

# Font Fallback

Professional developers write:

```css
font-family:Arial, Helvetica, sans-serif;
```

---

Why?

Suppose Arial unavailable.

Browser tries:

```text
Helvetica
```

Still unavailable?

Browser uses:

```text
sans-serif
```

---

# Memory Story

Imagine:

```text

Take Bus 2

Bus 2 missed

Take Bus 3
```

Fallback fonts work exactly like that.

# PROPERTY 12

# white-space

One of the most misunderstood properties.

---

# Normal

```css
white-space:normal;
```

Browser wraps text automatically.

---

Example

```text
This is a very very very very long sentence.
```

Becomes

```text
This is a very very

very very long

sentence.
```

---

# No Wrap

```css
white-space:nowrap;
```

Everything stays on one line.

---

Output

```text
This is a very very very very long sentence.
```

Single line.

---

# Real Example

Navigation Menu

```css
nav a
{
 white-space:nowrap;
}
```

Prevents menu text breaking.

---

# Memory Trick

No Wrap

=

Do not fold paper.

Keep it straight.

# PROFESSIONAL TYPOGRAPHY RULES

---

## Rule 1

Body text should not be too small.

Good:

```css
font-size:16px;
```

or

```css
font-size:18px;
```

---

## Rule 2

Paragraphs need breathing space.

```css
line-height:1.5;
```

or

```css
line-height:1.8;
```

---

## Rule 3

Avoid too many fonts.

Good:

```text
1–2 fonts
```

Bad:

```text
6 different fonts
```

---

## Rule 4

Headings must stand out.

Use:

```css
font-size
font-weight
letter-spacing
```

---

## Rule 5

Content readability is more important than decoration.

Professional websites focus on readability first.
