# REAL LIFE ANALOGY

Imagine a family.

```text
Father

↓

Son

↓

Grandson
```

Certain things are inherited.

Example:

```text
Surname

Language

Culture
```

pass from parent to child.

---

CSS works similarly.

Some properties pass from parent to child.

This process is called:

# INHERITANCE

---

# Definition

Inheritance means:

```text
Child elements automatically
receive some properties
from parent elements.
```

---

# Example

HTML

```html
<div>

<h1>
CSS
</h1>

<p>
Frontend
</p>

</div>
```

CSS

```css
div
{
 color:blue;
}
```

Output:

```text
CSS       -> Blue

Frontend  -> Blue
```

---

Why?

Because:

```text
color
```

is inheritable.

---

# MEMORY TRICK

Think:

```text
Parent Gives Gifts
To Children
```

If property is inheritable,

children receive the gift.
