# BLOCK ELEMENTS

---

## Definition

A block element:

```text
Starts on a new line

Takes full available width
```

---

# Example

```html

<p>Paragraph</p>

<div>Box</div>
```

All are block elements.

Because:

```text

Height doesn't work properly

on inline elements
```

They don't want large boxes.

# BLOCK VS INLINE

| Feature      | Block | Inline |
| ------------ | ----- | ------ |
| New Line     | Yes   | No     |
| Full Width   | Yes   | No     |
| Width Works  | Yes   | No     |
| Height Works | Yes   | No     |

---

# THE SOLUTION

# INLINE-BLOCK

Professional developers often need:

```text
Stay on same line

AND

Allow width/height
```

---

This is where:

```css
display:inline-block;
```

enters.

---

# Example

```html
<div class="box">
HTML
</div>

<div class="box">
CSS
</div>

<div class="box">
JS
</div>
```

---

CSS

```css
.box
{
 display:inline-block;

 width:150px;

 height:150px;

 background:skyblue;
}
```

---

Output

```text
┌─────┐ ┌─────┐ ┌─────┐
│HTML │ │CSS  │ │ JS  │
└─────┘ └─────┘ └─────┘
```

---

# What Happened?

Same line.

AND

Width works.

AND

Height works.

Best of both worlds.

# What is Static?

Default position of every element.

---

Example

```html

<h1>CSS</h1>

<h1>JavaScript</h1>
```

---

Visual

```text

CSS

JavaScript
```

---

CSS

```css
h1
{
 position:static;
}
```

No change.

Because static is default.

---

# Important Rule

With static:

```css

left
right
bottom
```

DO NOT WORK.

---

Example

```css

}
```

Nothing happens.

# POSITION: ABSOLUTE

This is where real website magic begins.

---

# Meaning

Element leaves normal document flow.

Positioned relative to nearest positioned parent.

---

Don't memorize.

Let's understand visually.

```html
</div>
```

---

```css
 background:red;
}
```

Output

```text

│             NEW │
│                 │
│                 │
└─────────────────┘
```
