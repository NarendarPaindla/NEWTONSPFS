---

# Difference

RGBA affects color transparency.

Opacity affects entire element.

---

Example

```css
background:
rgba(255,0,0,.5);
```

Only background becomes transparent.

---

```css
opacity:.5;
```

Everything becomes transparent.

Text included.

---

# PROFESSIONAL COLOR RULE

Never use:

```css
opacity:.5;
```

for cards containing text.

Use RGBA instead.

Most students do this:

```css

 color:red;

}

{

}
```

```text
Color Chaos
```

Website looks like a festival poster.

Not a professional product.

# Professional Developers Think Differently

They don't choose colors randomly.

They build a:

```text

```

