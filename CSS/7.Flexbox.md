# CSS MASTERCLASS – FLEXBOX (PART 1)

# Understanding Flexbox From Zero

## The Layout System That Changed CSS Forever

---

# Before Flexbox

Let's understand the pain.

Imagine you want this layout:

```text
┌─────┐ ┌─────┐ ┌─────┐
│HTML │ │ CSS │ │ JS  │
└─────┘ └─────┘ └─────┘
```

Before Flexbox developers used:

```css
float:left;
```

or

```css
display:inline-block;
```

Problems:

❌ Hard to center

❌ Hard to align

❌ Hard to make responsive

❌ Complex code

❌ Lots of bugs

---

# Then Flexbox Arrived

When Flexbox was introduced, developers felt:

```text
Finally!
```

Because Flexbox solves layout problems beautifully.

---

# What is Flexbox?

Flexbox = Flexible Box Layout

It is a one-dimensional layout system.

Meaning:

It controls elements in:

```text
Row
OR
Column
```

---

# Memory Trick

Imagine a School Bus.

```text
┌─────────────────────┐
│ A │ B │ C │ D │ E │
└─────────────────────┘
```

Bus = Container

Students = Items

Flexbox controls:

* Where students sit
* Distance between students
* Alignment of students
* Order of students

# The FLEX Property

Professionals often write:

```css
flex:1;
```

instead of:

```css
flex-grow:1;
```

---

Why?

Because:

```css

```

is shorthand.

---

Example

```css

```

means roughly:

```css
flex-grow:1;

flex-shrink:1;

flex-basis:0;
```

# align-self

Remember:

```css
align-items
```

controls all children.

---

Example

```css
.container
{
 align-items:center;
}
```

All items centered.

---

But what if one item must behave differently?

---

Solution

```css
align-self
```

---

Example

```css
.two
{
 align-self:flex-start;
}
```

---

Visual

```text
┌────────────────────┐

      1

2

      3

└────────────────────┘
```

Only item 2 changes.

---

# Memory Trick

Classroom Rule

Everyone follows.

---

align-self

=

Special Permission

One student behaves differently.
