# Lesson 1: What are Aggregate Functions?

## Definition

Aggregate Functions perform calculations on **multiple rows** and return **a single value**.

---

## Real-Life Example

Suppose a teacher asks:

* How many students are there?
* What is the highest mark?
* What is the average mark?
* What is the total of all marks?

Instead of calculating manually, SQL can do it instantly.

| `MIN()`   | Finds the smallest value |

# Lesson 3: COUNT()

## Definition

Counts the number of rows.

---

## Syntax

```sql
SELECT COUNT(*)
FROM Students;
```

---

## Internal Execution

```text
Students Table

↓

Read Row 1 → Count = 1

↓

Read Row 2 → Count = 2

↓

Read Row 3 → Count = 3

↓

...

↓

Read Last Row

↓

Return Count
```

---

## Output

| COUNT(*) |
| -------- |
| 7        |

---

### COUNT(Column)

```sql
SELECT COUNT(Marks)
FROM Students;
```

Counts only rows where `Marks` is **NOT NULL**.

---

### Difference

Suppose:

| Name  | Marks |
| ----- | ----- |
| Rahul | 90    |
| Priya | 95    |
| Arjun | NULL  |

```sql
SELECT COUNT(*)
FROM Students;
```

Output

```
3
```

---

```sql
SELECT COUNT(Marks)
FROM Students;
```

Output

```
2
```

Because `NULL` is ignored.

# Common Mistakes

### ❌ Using Aggregate Function with `*`

Wrong

```sql
SELECT SUM(*)
FROM Students;
```

Correct

```sql
SELECT SUM(Marks)
FROM Students;
```

---

### ❌ Using AVG on Text

Wrong

```sql
SELECT AVG(Name)
FROM Students;
```

`AVG()` works on numeric data.

---

### ❌ Confusing `COUNT(*)` and `COUNT(Column)`

Remember:

* `COUNT(*)` counts **all rows**.
* `COUNT(Column)` counts only **non-NULL values** in that column.
