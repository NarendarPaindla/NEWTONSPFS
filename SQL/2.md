# Lesson 1: Why Do We Need ORDER BY?

Suppose the Principal asks:

> "Show the students with the highest marks first."

If you run:

```sql
SELECT *
FROM Students;
```

The output appears in the order the rows were inserted, **not** by marks.

To arrange the records, we use **`ORDER BY`**.

---

# Lesson 2: ORDER BY (Ascending Order)

## Definition

`ORDER BY` sorts the records.

By default, sorting is **Ascending (`ASC`)**.

---

## Syntax

```sql
SELECT column_names
FROM table_name
ORDER BY column_name;
```

or

```sql
SELECT column_names
FROM table_name
ORDER BY column_name ASC;
```

---

## Example

```sql
SELECT *
FROM Students
ORDER BY Marks;
```

---

## Internal Execution Process

```text
Student writes query

↓

Parser checks syntax

↓

Read all rows

↓

Sort Marks (Small → Large)

↓

Display sorted rows
```

---

## Output

| StudentID | Name  | Marks |
| --------- | ----- | ----- |
| 107       | Ravi  | 70    |
| 105       | Kiran | 76    |
| 103       | Arjun | 82    |
| 104       | Sneha | 88    |
| 101       | Rahul | 90    |
| 106       | Meena | 91    |
| 102       | Priya | 95    |

# Lesson 6: LIMIT

## Definition

`LIMIT` returns only the first **N rows**.

---

| --------- | ----- |

## Internal Process

```text

↓

↓

Stop Reading

↓

Display
```

# Lesson 8: LIMIT with OFFSET

## Definition

`OFFSET` skips rows before returning data.

---

## Syntax

```sql
SELECT *
FROM Students
LIMIT 3 OFFSET 2;
```

Meaning

```text
Skip first 2 rows

↓

Return next 3 rows
```

---

## Output

| StudentID | Name  |
| --------- | ----- |
| 103       | Arjun |
| 104       | Sneha |
| 105       | Kiran |

# Common Mistakes

### ❌ Forgetting ORDER BY

Wrong

```sql
SELECT *
FROM Students
DESC;
```

Correct

```sql
SELECT *
FROM Students
ORDER BY Marks DESC;
```

---

### ❌ Wrong LIMIT Syntax

Wrong

```sql
SELECT *
FROM Students
LIMIT;
```

Correct

```sql
SELECT *
FROM Students
LIMIT 5;
```

---

### ❌ Wrong OFFSET

Wrong

```sql
OFFSET -5
```

Offset cannot be negative.
