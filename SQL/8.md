# Lesson 1: Why Do We Need Multiple Tables?

Suppose we store everything in one table.

## Students Table

| 103       | Priya | ECE        | Dr. Ramesh |


A **Primary Key** uniquely identifies every row.

Primary Key


```sql

    DepartmentID INT PRIMARY KEY,

);
```

---

## Students

```sql
CREATE TABLE Students(
    StudentID INT PRIMARY KEY,
    Name VARCHAR(50),
    Age INT,
    Marks INT,
    DepartmentID INT,
    FOREIGN KEY(DepartmentID)
    REFERENCES Departments(DepartmentID)
);
```

# Lesson 8: INNER JOIN

## Definition

Returns **only matching rows** from both tables.

---

Syntax

```sql
SELECT
s.StudentID,
s.Name,
d.DepartmentName,
d.HOD
FROM Students s
INNER JOIN Departments d
ON s.DepartmentID = d.DepartmentID;
```

---

Internal Execution

```text
Read Student Row

↓

DepartmentID = 1

↓

Search Departments

↓

Found

↓

Combine Row

↓

Display

↓

Repeat
```

---

Output

| StudentID | Name  | Department | HOD        |
| --------- | ----- | ---------- | ---------- |
| 101       | Rahul | CSE        | Dr. Kumar  |
| 102       | Priya | ECE        | Dr. Ramesh |
| 103       | Arjun | IT         | Dr. Ravi   |
| 104       | Sneha | CSE        | Dr. Kumar  |
| 106       | Meena | IT         | Dr. Ravi   |

Notice

Kiran is NOT displayed.

# Lesson 9: LEFT JOIN

Returns

All rows from LEFT table.

Matching rows from RIGHT table.

---

```sql
SELECT
s.StudentID,
s.Name,
d.DepartmentName
FROM Students s
LEFT JOIN Departments d
ON s.DepartmentID = d.DepartmentID;
```

---

Output

| Name  | Department |
| ----- | ---------- |
| Rahul | CSE        |
| Priya | ECE        |
| Arjun | IT         |
| Sneha | CSE        |
| Kiran | NULL       |
| Meena | IT         |

Notice

Kiran appears because LEFT JOIN keeps all student records.

# Lesson 10: RIGHT JOIN

# Lesson 12: SELF JOIN

A table joins with itself.

Example

Employees

| Employee | ManagerID |
| -------- | --------- |
| Rahul    | 2         |
| Priya    | 3         |

---

```sql
SELECT
e.EmployeeName,
m.EmployeeName AS Manager
FROM Employees e
JOIN Employees m
ON e.ManagerID = m.EmployeeID;
```

# Common Mistakes

### ❌ Forgetting ON Clause

Wrong

```sql
SELECT *
FROM Students
JOIN Departments;
```

Correct

```sql
SELECT *
FROM Students
JOIN Departments
ON Students.DepartmentID=Departments.DepartmentID;
```

---

### ❌ Wrong Join Column

Wrong

```sql
ON StudentID=DepartmentID
```

Correct

```sql
ON Students.DepartmentID=Departments.DepartmentID
```

---

### ❌ Selecting Ambiguous Columns

Wrong

```sql
SELECT DepartmentID
```

If both tables have `DepartmentID`, MySQL reports an ambiguous column error.

Correct

```sql
SELECT s.DepartmentID
```

or

```sql
SELECT d.DepartmentID
```
