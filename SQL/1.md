# Lesson 1: What is WHERE?

## Definition

The `WHERE` clause is used to **filter records** based on a condition.

Without `WHERE`:

```sql
SELECT * FROM Students;
```

Output:

All students are displayed.

With `WHERE`:

```sql
SELECT *
FROM Students
WHERE Department = 'CSE';
```

Only CSE students are displayed.

---

## Real-Life Example

Imagine your college has **10,000 students**.

The principal asks:

> "Show only CSE students."

You don't bring all 10,000 records.

You filter only the required students.

This is exactly what `WHERE` does.

# Lesson 3: Comparison Operators

| Operator     | Meaning               | Example               |
| ------------ | --------------------- | --------------------- |
| `=`          | Equal to              | `Marks = 90`          |
| `>`          | Greater than          | `Marks > 80`          |
| `<`          | Less than             | `Marks < 80`          |
| `>=`         | Greater than or equal | `Marks >= 90`         |
| `<=`         | Less than or equal    | `Marks <= 80`         |

# Lesson 4: Logical Operators

## AND

Both conditions must be true.

```sql
SELECT *
FROM Students
WHERE Department = 'CSE'
AND Marks > 80;
```

Output

| Name  | Department | Marks |
| ----- | ---------- | ----- |
| Rahul | CSE        | 90    |
| Sneha | CSE        | 88    |

---

### Internal Logic

```text
Department = CSE ?

↓

Yes

↓

Marks > 80 ?

↓

Yes

↓

Display
```

---

## OR

At least one condition must be true.

```sql
SELECT *
FROM Students
WHERE Department = 'CSE'
OR Department = 'IT';
```

Output

All CSE and IT students.

---

### Internal Logic

```text
Department = CSE ?

↓

Yes

↓

Display

OR

Department = IT ?

↓

Yes

↓

Display
```

---

## NOT

Reverses the condition.

```sql
SELECT *
FROM Students
WHERE NOT Department = 'EEE';
```

Output

All students except EEE.

---

# Lesson 5: IN Operator

Instead of multiple `OR` conditions:

```sql
SELECT *
FROM Students
WHERE Department = 'CSE'
OR Department = 'IT';
```

Use:

```sql
SELECT *
FROM Students
WHERE Department IN ('CSE', 'IT');
```

Output

Students from CSE and IT.

# Lesson 8: Wildcards

## `%`

Matches **zero or more characters**.

Examples:

```sql
LIKE 'A%'
```

Starts with A.

```sql
LIKE '%a'
```

Ends with a.

```sql
LIKE '%e%'
```

Contains e.

---

## `_`

Matches exactly **one character**.

Example:

```sql
SELECT *
FROM Students
WHERE Name LIKE '_a%';
```

Matches names where the **second character is 'a'**.

# Lesson 9: NULL Values

Suppose one student doesn't have marks yet.

| Name | Marks |
| ---- | ----- |
| Anil | NULL  |

---

## IS NULL

```sql
SELECT *
FROM Students
WHERE Marks IS NULL;
```

Displays students whose marks are unknown.

---

## IS NOT NULL

```sql
SELECT *
FROM Students
WHERE Marks IS NOT NULL;
```

Displays students with marks entered.

---

## Why Not Use `= NULL`?

Wrong:

```sql
SELECT *
FROM Students
WHERE Marks = NULL;
```

This returns **no rows** because `NULL` is not compared using `=`.

Correct:

```sql
SELECT *
FROM Students
WHERE Marks IS NULL;
```

# Common Mistakes

### ❌ Using `=` instead of `IS NULL`

```sql
WHERE Marks = NULL
```

Correct:

```sql
WHERE Marks IS NULL
```

---

### ❌ Forgetting Quotes Around Strings

Wrong:

```sql
WHERE Department = CSE
```

Correct:

```sql
WHERE Department = 'CSE'
```

---

### ❌ Using `BETWEEN` Incorrectly

Wrong:

```sql
WHERE Marks BETWEEN 90 80
```

Correct:

```sql
WHERE Marks BETWEEN 80 AND 90
```
