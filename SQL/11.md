# Lesson 2: What is JOIN?

## Definition

A **JOIN** combines rows from two or more tables based on a related column.

Usually, the related column is:

* Primary Key
* Foreign Key

---

## Real-Life Example

Think of two Excel sheets.

### Sheet 1

| Roll No | Name  |
| ------- | ----- |
| 101     | Rahul |

---

### Sheet 2

| Roll No | Marks |
| ------- | ----- |
| 101     | 90    |

JOIN merges them into:

| Roll No | Name  | Marks |
| ------- | ----- | ----- |
| 101     | Rahul | 90    |

# Lesson 3: Primary Key

A **Primary Key** uniquely identifies every record.

```sql
CREATE TABLE Departments(
DepartmentID INT PRIMARY KEY,
DepartmentName VARCHAR(50)
);
```

Properties

* Unique
* Not NULL
* One Primary Key per table

---

# Lesson 4: Foreign Key

A **Foreign Key** creates a relationship between two tables.

```sql
CREATE TABLE Students(
StudentID INT PRIMARY KEY,
Name VARCHAR(50),
DepartmentID INT,
FOREIGN KEY (DepartmentID)
REFERENCES Departments(DepartmentID)
);
```

Relationship

```text
Departments

DepartmentID (PK)

        ↑

Students

DepartmentID (FK)
```

# Lesson 6: INNER JOIN

## Definition

Returns **only matching rows** from both tables.

---

## Syntax

```sql
SELECT
s.StudentID,
s.Name,
d.DepartmentName,
d.HOD
FROM Students s
INNER JOIN Departments d
ON s.DepartmentID=d.DepartmentID;
```

---

## Internal Process

```text
Rahul

↓

DepartmentID=1

↓

Search Departments

↓

Found

↓

Merge

↓

Display
```

Repeat for every row.

---

## Output

| Student | Department |
| ------- | ---------- |
| Rahul   | CSE        |
| Priya   | ECE        |
| Arjun   | IT         |
| Sneha   | CSE        |

Kiran

↓

No matching department

↓

Ignored

Meena

↓

NULL

↓

Ignored

# Lesson 9: FULL OUTER JOIN

MySQL **does not support FULL OUTER JOIN directly**.

It can be achieved using `UNION`.

```sql
SELECT
s.Name,
d.DepartmentName
FROM Students s
LEFT JOIN Departments d
ON s.DepartmentID=d.DepartmentID

UNION

SELECT
s.Name,
d.DepartmentName
FROM Students s
RIGHT JOIN Departments d
ON s.DepartmentID=d.DepartmentID;
```

---

Output

Contains

* Every student
* Every department

# Lesson 11: SELF JOIN

A table joins itself.

---

Employees

| EmployeeID | Employee | ManagerID |
| ---------- | -------- | --------- |
| 1          | Rahul    | 3         |
| 2          | Priya    | 3         |
| 3          | Ramesh   | NULL      |

---

```sql
SELECT
e.EmployeeName,
m.EmployeeName AS Manager
FROM Employees e
JOIN Employees m
ON e.ManagerID=m.EmployeeID;
```

---

Output

| Employee | Manager |
| -------- | ------- |
| Rahul    | Ramesh  |
| Priya    | Ramesh  |

# Lesson 14: Which JOIN Should We Use?

| Situation                 | JOIN                                   |
| ------------------------- | -------------------------------------- |
| Only matching records     | INNER JOIN                             |
| All left table rows       | LEFT JOIN                              |
| All right table rows      | RIGHT JOIN                             |
| Every combination         | CROSS JOIN                             |
| Employee → Manager        | SELF JOIN                              |
| All rows from both tables | FULL OUTER JOIN (using UNION in MySQL) |

# Common Mistakes

### ❌ Forgetting `ON`

```sql
SELECT *
FROM Students
JOIN Departments;
```

Error or unintended Cartesian product (depending on syntax and database).

---

### ❌ Joining Wrong Columns

```sql
ON StudentID = DepartmentID
```

Wrong

Correct

```sql
ON Students.DepartmentID = Departments.DepartmentID
```

---

### ❌ Ambiguous Columns

Wrong

```sql
SELECT DepartmentID
FROM Students
JOIN Departments
ON Students.DepartmentID = Departments.DepartmentID;
```

If both tables contain `DepartmentID`, MySQL reports an ambiguous column error.

Correct

```sql
SELECT Students.DepartmentID
FROM Students
JOIN Departments
ON Students.DepartmentID = Departments.DepartmentID;
```

or use aliases:

```sql
SELECT s.DepartmentID
FROM Students s
JOIN Departments d
ON s.DepartmentID = d.DepartmentID;
```

## 🧠 Quick Revision Table

| JOIN Type           | Returns                                                                         |
| ------------------- | ------------------------------------------------------------------------------- |
| **INNER JOIN**      | Only matching rows from both tables                                             |
| **LEFT JOIN**       | All rows from the left table + matching rows from the right                     |
| **RIGHT JOIN**      | All rows from the right table + matching rows from the left                     |
| **FULL OUTER JOIN** | All rows from both tables (simulate with `LEFT JOIN UNION RIGHT JOIN` in MySQL) |
| **CROSS JOIN**      | Every possible combination of rows                                              |
| **SELF JOIN**       | A table joined with itself                                                      |
