Excellent! This is one of the **most critical modules** in SQL. Students must understand that these commands **modify or remove data**, so they should always be used carefully.

> **Golden Rule to teach students:**
>
> **Always execute a `SELECT` with the same `WHERE` condition before running an `UPDATE` or `DELETE`.**
>
> Example:
>
> ```sql
> SELECT * FROM Students WHERE StudentID = 101;
> ```
>
> Verify the rows first, then run:
>
> ```sql
> UPDATE Students
> SET Marks = 95
> WHERE StudentID = 101;
> ```

`TRUNCATE` removes **all rows** from a table.

# Lesson 12: DELETE vs TRUNCATE

| DELETE                            | TRUNCATE                     |
| --------------------------------- | ---------------------------- |
| DML                               | DDL                          |
| Can use `WHERE`                   | Cannot use `WHERE`           |
| Deletes selected rows or all rows | Deletes all rows             |
| Row-by-row deletion               | Removes all rows efficiently |
| Table remains                     | Table remains                |

---

# Lesson 13: DELETE vs TRUNCATE vs DROP

| Feature                 | DELETE | TRUNCATE | DROP |
| ----------------------- | ------ | -------- | ---- |
| Removes rows            | ✅      | ✅        | ✅    |
| Removes table structure | ❌      | ❌        | ✅    |
| Supports `WHERE`        | ✅      | ❌        | ❌    |
| Table remains           | ✅      | ✅        | ❌    |
| Command Type            | DML    | DDL      | DDL  |

# Common Mistakes

## ❌ Forgetting WHERE in UPDATE

Wrong

```sql
UPDATE Students
SET Marks = 100;
```

All rows are updated.

---

## ❌ Forgetting WHERE in DELETE

Wrong

```sql
DELETE FROM Students;
```

All rows are deleted.

---

## ❌ Using WHERE with TRUNCATE

Wrong

```sql
TRUNCATE TABLE Students
WHERE StudentID = 101;
```

This is invalid because `TRUNCATE` **does not support** a `WHERE` clause.
