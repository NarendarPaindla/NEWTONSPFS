> **Teaching Tip (Golden Rule):**
>
> * **`WHERE` filters rows** (before grouping).
> * **`HAVING` filters groups** (after grouping).

# Lesson 1: Why Do We Need HAVING?

Suppose the Principal asks:

> "Show only the departments whose average marks are greater than 85."

Can we use:

```sql id="2n97do"
SELECT Department,
AVG(Marks)
FROM Students
WHERE AVG(Marks) > 85
GROUP BY Department;
```

❌ No!

`WHERE` cannot use aggregate functions.

We use `HAVING`.

---

# Lesson 2: What is HAVING?

## Definition

`HAVING` filters **groups** after `GROUP BY` has created them.

---

## Syntax

```sql id="ex84gb"
SELECT column_name,
aggregate_function(column_name)
FROM table_name
GROUP BY column_name
HAVING condition;
```

---

# Lesson 3: First HAVING Query

```sql id="u0umtv"
SELECT Department,
AVG(Marks) AS AverageMarks
FROM Students
GROUP BY Department
HAVING AVG(Marks) > 85;
```

---

## Internal Execution

```text id="2xd17h"
Read Students Table

↓

Create Department Groups

↓

Calculate Average

↓

CSE → 82.67

ECE → 95

EEE → 76

IT → 86.50

↓

Keep Only Groups

Average > 85

↓

Display
```

| ECE        | 95.00        |
| IT         | 86.50        |

# Lesson 7: WHERE vs HAVING

Suppose the Principal asks:

> "Among students scoring more than 80, show departments whose average marks are above 85."

---

Correct Query

```sql id="zwrg79"
SELECT Department,
AVG(Marks) AS AverageMarks
FROM Students
WHERE Marks > 80
GROUP BY Department
HAVING AVG(Marks) > 85;
```

---

## Internal Execution Order

```text id="a5yfe4"
Students Table

↓

WHERE Marks > 80

↓

Remaining Rows

↓

GROUP BY Department

↓

Calculate Average

↓

HAVING AVG(Marks) > 85

↓

Display Result
```

---

## Output

| Department | AverageMarks |
| ---------- | ------------ |
| ECE        | 95.00        |

# Lesson 8: WHERE vs HAVING Comparison

| WHERE                          | HAVING                      |
| ------------------------------ | --------------------------- |
| Filters rows                   | Filters groups              |
| Executed before `GROUP BY`     | Executed after `GROUP BY`   |
| Cannot use aggregate functions | Can use aggregate functions |
| Works on individual records    | Works on grouped results    |

---

## Example

### WHERE

```sql id="dfnd1p"
SELECT *
FROM Students
WHERE Marks > 80;
```

Rows are filtered first.

---

### HAVING

```sql id="d3p2s3"
SELECT Department,
AVG(Marks)
FROM Students
GROUP BY Department
HAVING AVG(Marks) > 85;
```

Groups are filtered after grouping.

---

# Lesson 9: Multiple Conditions in HAVING

```sql id="m2bcd8"
SELECT Department,
COUNT(*) AS TotalStudents,
AVG(Marks) AS AverageMarks
FROM Students
GROUP BY Department
HAVING COUNT(*) >= 2
AND AVG(Marks) > 80;
```

---

## Output

| Department | TotalStudents | AverageMarks |
| ---------- | ------------- | ------------ |
| CSE        | 3             | 82.67        |
| IT         | 2             | 86.50        |

# Lesson 10: HAVING with ORDER BY

Display departments by average marks (highest first).

```sql id="w2ezly"
SELECT Department,
AVG(Marks) AS AverageMarks
FROM Students
GROUP BY Department
HAVING AVG(Marks) > 75
ORDER BY AverageMarks DESC;
```

---

## Output

| Department | AverageMarks |
| ---------- | ------------ |
| ECE        | 95.00        |
| IT         | 86.50        |
| CSE        | 82.67        |
| EEE        | 76.00        |

# Common Mistakes

## ❌ Using Aggregate Functions in WHERE

Wrong

```sql id="9z2qbd"
WHERE AVG(Marks) > 80
```

Correct

```sql id="lfexeh"
HAVING AVG(Marks) > 80
```

---

## ❌ Using HAVING Without GROUP BY (Not Recommended for Beginners)

Although MySQL allows some cases, beginners should avoid it until they fully understand grouping.

---

## ❌ Confusing WHERE and HAVING

Remember:

```text id="fzycvp"
WHERE

↓

Rows

------------------

HAVING

↓

Groups
```
