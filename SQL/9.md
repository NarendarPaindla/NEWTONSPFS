# Lesson 1: What are Integrity Constraints?

## Definition

**Integrity Constraints** are rules applied to a table to ensure that the data stored in the database is **accurate, valid, and consistent**.

Without constraints, users can insert invalid or duplicate data.

---

## Real-Life Example

Imagine a college admission form.

Rules:

* Student ID must be unique.
* Name cannot be empty.
* Age should be greater than 17.
* Gender should be Male or Female.
* Department must exist.

These rules are called **constraints**.

---

# Lesson 2: Why Do We Need Constraints?

Suppose we have the following table:

| StudentID | Name  | Marks |
| --------- | ----- | ----- |
| 101       | Rahul | 90    |
| 101       | Rahul | 95    |
| NULL      |       | 120   |

Problems:

* Duplicate Student IDs
* Empty Name
* Invalid Marks

Constraints prevent these problems.

---

# Lesson 3: Types of Integrity Constraints

| Constraint     | Purpose                             |
| -------------- | ----------------------------------- |
| NOT NULL       | Prevents NULL values                |
| UNIQUE         | Prevents duplicate values           |
| PRIMARY KEY    | Unique + NOT NULL                   |
| FOREIGN KEY    | Maintains relationships             |
| CHECK          | Validates data based on a condition |
| DEFAULT        | Assigns a default value             |
| AUTO_INCREMENT | Automatically generates values      |

# Lesson 4: NOT NULL Constraint

## Definition

A column with `NOT NULL` **must always contain a value**.

---

## Syntax

```sql
CREATE TABLE Students(
    StudentID INT,
    Name VARCHAR(50) NOT NULL
);
```

---

## Insert Valid Data

```sql
INSERT INTO Students
VALUES(101,'Rahul');
```

Success

---

## Insert Invalid Data

```sql
INSERT INTO Students
VALUES(102,NULL);
```

Error

```text
Column 'Name' cannot be null
```

---

## Internal Working

```text
Student enters data

↓

MySQL checks

↓

Is Name NULL?

↓

Yes

↓

Reject Row

↓

Display Error
```

# Lesson 5: UNIQUE Constraint

## Definition

A `UNIQUE` column cannot contain duplicate values.

---

## Syntax

```sql
CREATE TABLE Students(
    StudentID INT,
    Email VARCHAR(100) UNIQUE
);
```

---

## Valid Inserts

```sql
INSERT INTO Students
VALUES(101,'rahul@gmail.com');

INSERT INTO Students
VALUES(102,'priya@gmail.com');
```

---

## Invalid Insert

```sql
INSERT INTO Students
VALUES(103,'rahul@gmail.com');
```

Error

```text
Duplicate entry
```

---

# Lesson 6: PRIMARY KEY

## Definition

A Primary Key uniquely identifies every record.

It combines:

* `UNIQUE`
* `NOT NULL`

---

## Syntax

```sql
CREATE TABLE Students(
    StudentID INT PRIMARY KEY,
    Name VARCHAR(50)
);
```

---

## Rules

* Cannot be NULL
* Cannot be duplicated
* One Primary Key per table
* Can consist of multiple columns (Composite Key)

---

## Invalid Example

```sql
INSERT INTO Students
VALUES(101,'Rahul');

INSERT INTO Students
VALUES(101,'Priya');
```

Error

Duplicate Primary Key.

---

# Lesson 7: FOREIGN KEY

## Definition

A Foreign Key creates a relationship between two tables.

---

Departments

| DepartmentID | Department |
| ------------ | ---------- |
| 1            | CSE        |
| 2            | ECE        |

---

Students

| StudentID | Name  | DepartmentID |
| --------- | ----- | ------------ |
| 101       | Rahul | 1            |

---

## Syntax

```sql
CREATE TABLE Departments(
    DepartmentID INT PRIMARY KEY,
    DepartmentName VARCHAR(50)
);

CREATE TABLE Students(
    StudentID INT PRIMARY KEY,
    Name VARCHAR(50),
    DepartmentID INT,
    FOREIGN KEY (DepartmentID)
    REFERENCES Departments(DepartmentID)
);
```

---

## Valid Insert

```sql
INSERT INTO Students
VALUES(101,'Rahul',1);
```

---

## Invalid Insert

```sql
INSERT INTO Students
VALUES(102,'Priya',5);
```

Error

Department 5 does not exist.

---

## Internal Working

```text
Insert Student

↓

Check DepartmentID

↓

Exists?

↓

Yes

↓

Insert Row

No

↓

Reject
```

# Lesson 8: CHECK Constraint

## Definition

`CHECK` ensures that data satisfies a condition.

---

## Syntax

```sql
CREATE TABLE Students(
    StudentID INT,
    Age INT CHECK(Age >= 18)
);
```

---

## Valid Insert

```sql
INSERT INTO Students
VALUES(101,20);
```

---

## Invalid Insert

```sql
INSERT INTO Students
VALUES(102,15);
```

Error

CHECK constraint violated.

---

## Another Example

```sql
CREATE TABLE Employees(
    Salary DECIMAL(10,2)
    CHECK(Salary > 0)
);
```

---

# Lesson 9: DEFAULT Constraint

## Definition

Assigns a value automatically if none is provided.

---

## Syntax

```sql
CREATE TABLE Students(
    StudentID INT,
    City VARCHAR(50)
    DEFAULT 'Hyderabad'
);
```

---

Insert

```sql
INSERT INTO Students(StudentID)
VALUES(101);
```

---

Output

| StudentID | City      |
| --------- | --------- |
| 101       | Hyderabad |

---

# Lesson 10: AUTO_INCREMENT

## Definition

Automatically generates sequential numbers.

---

## Syntax

```sql
CREATE TABLE Students(
    StudentID INT AUTO_INCREMENT,
    Name VARCHAR(50),
    PRIMARY KEY(StudentID)
);
```

---

Insert

```sql
INSERT INTO Students(Name)
VALUES
('Rahul'),
('Priya'),
('Arjun');
```

---

Output

| StudentID | Name  |
| --------- | ----- |
| 1         | Rahul |
| 2         | Priya |
| 3         | Arjun |

# Lesson 11: Composite Primary Key

Sometimes a single column is not enough.

Example

Attendance

| StudentID | SubjectID | Date |
| --------- | --------- | ---- |

One student can attend many subjects.

Use both columns together.

```sql
CREATE TABLE Attendance(
    StudentID INT,
    SubjectID INT,
    AttendanceDate DATE,
    PRIMARY KEY(StudentID, SubjectID)
);
```

# Lesson 12: Adding Constraints using ALTER TABLE

## Add NOT NULL

```sql
ALTER TABLE Students
MODIFY Name VARCHAR(50) NOT NULL;
```

---

## Add UNIQUE

```sql
ALTER TABLE Students
ADD CONSTRAINT UK_Email
UNIQUE(Email);
```

---

## Add PRIMARY KEY

```sql
ALTER TABLE Students
ADD PRIMARY KEY(StudentID);
```

---

## Add FOREIGN KEY

```sql
ALTER TABLE Students
ADD CONSTRAINT FK_Department
FOREIGN KEY(DepartmentID)
REFERENCES Departments(DepartmentID);
```

---

# Lesson 13: Dropping Constraints

## Drop Primary Key

```sql
ALTER TABLE Students
DROP PRIMARY KEY;
```

---

## Drop Foreign Key

```sql
ALTER TABLE Students
DROP FOREIGN KEY FK_Department;
```

---

## Drop Unique

```sql
ALTER TABLE Students
DROP INDEX UK_Email;
```

# Common Mistakes

### ❌ Duplicate Primary Key

```sql
INSERT INTO Students
VALUES(1,'Rahul');

INSERT INTO Students
VALUES(1,'Priya');
```

---

### ❌ NULL in NOT NULL Column

```sql
INSERT INTO Students
VALUES(NULL);
```

---

### ❌ Invalid Foreign Key

```sql
DepartmentID = 100
```

Department does not exist.

---

### ❌ Violating CHECK

```sql
Age = 15
```

When the rule is `Age >= 18`.
