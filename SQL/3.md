# Lesson 1: What is a Function?

## Definition

A **Function** is a predefined program that accepts input, performs an operation, and returns an output.

Think of it like a calculator.

Example:

```
ABS(-10)

↓

10
```

The function receives **-10** as input and returns **10**.

---

## Real-Life Example

Imagine a juice machine.

```
Fruits

↓

Juice Machine

↓

Juice
```

Similarly,

```
Input Value

↓

SQL Function

↓

Output Value
```

# Lesson 3: String Functions

String functions work with text values.

---

## LENGTH()

Returns the number of characters.

```sql
SELECT LENGTH('Rahul');
```

Output

| LENGTH('Rahul') |
| --------------- |
| 5               |

---

## UPPER()

Converts text to uppercase.

```sql
SELECT UPPER('rahul');
```

Output

| UPPER('rahul') |
| -------------- |
| RAHUL          |

---

## LOWER()

Converts text to lowercase.

```sql
SELECT LOWER('RAHUL');
```

Output

| LOWER('RAHUL') |
| -------------- |
| rahul          |

---

## CONCAT()

Joins two or more strings.

```sql
SELECT CONCAT('Rahul',' ','Reddy');
```

Output

| CONCAT(...) |
| ----------- |
| Rahul Reddy |

---

## TRIM()

Removes spaces from both sides.

```sql
SELECT TRIM('   Rahul   ');
```

Output

```
Rahul
```

---

## LEFT()

Returns characters from the left.

```sql
SELECT LEFT('Hyderabad',5);
```

Output

```
Hyder
```

---

## RIGHT()

Returns characters from the right.

```sql
SELECT RIGHT('Hyderabad',4);
```

Output

```
abad
```

---

## SUBSTRING()

Extracts part of a string.

```sql
SELECT SUBSTRING('Hyderabad',3,5);
```

Output

```
derab
```

# Common Mistakes

### ❌ Forgetting Quotes

Wrong

```sql
SELECT UPPER(Rahul);
```

Correct

```sql
SELECT UPPER('Rahul');
```

---

### ❌ Wrong SUBSTRING Position

```sql
SUBSTRING('Rahul',0,3)
```

MySQL starts positions from **1**, not **0**.

Correct

```sql
SUBSTRING('Rahul',1,3)
```

---

### ❌ Misspelling Function Names

Wrong

```sql
SELECT LENGHT(Name);
```

Correct

```sql
SELECT LENGTH(Name);
```
