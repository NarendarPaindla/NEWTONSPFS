Excellent! This is the module where students learn **how to generate reports**. In interviews and real-world projects, `GROUP BY` is one of the **most frequently used SQL clauses**.

> **Teaching Tip:** Explain the difference clearly:
>
> * **Aggregate Functions** → Calculate one result for the **entire table**.
> * **GROUP BY** → Divide the table into **groups**, then calculate one result **for each group**.

# Lesson 1: Why Do We Need GROUP BY?

Suppose the Principal asks:

> "How many students are there in each department?"

Without `GROUP BY`, you can only count the **entire table**.

```sql
SELECT COUNT(*)
FROM Students;
```

Output

| COUNT(*) |
| -------- |
| 7        |

But the Principal wants:

| Department | Students |
| ---------- | -------- |
| CSE        | 3        |
| ECE        | 1        |
| EEE        | 1        |
| IT         | 2        |

This is where `GROUP BY` is used.

---

# Lesson 2: What is GROUP BY?

## Definition

`GROUP BY` divides rows into groups based on one or more columns, then performs aggregate calculations on each group.

---

## Internal Concept

Original Table

| Name  | Department |
| ----- | ---------- |
| Rahul | CSE        |
| Sneha | CSE        |
| Ravi  | CSE        |
| Priya | ECE        |
| Kiran | EEE        |
| Arjun | IT         |
| Meena | IT         |

MySQL internally creates groups:

```text
CSE
├── Rahul
├── Sneha
└── Ravi

ECE
└── Priya

EEE
└── Kiran

IT
├── Arjun
└── Meena
```

Then it performs calculations separately for each group.

---

# Lesson 3: COUNT with GROUP BY

## Syntax

```sql
SELECT Department,
COUNT(*)
FROM Students
GROUP BY Department;
```

---

## Internal Execution

```text
Read Students Table

↓

Read Department Column

↓

Create Groups

↓

CSE

ECE

EEE

IT

↓

Count Rows in Each Group

↓

Display Results
```

---

## Output

| Department | COUNT(*) |
| ---------- | -------- |
| CSE        | 3        |
| ECE        | 1        |
| EEE        | 1        |
| IT         | 2        |

# Lesson 4: SUM with GROUP BY

Find total marks department-wise.

```sql
SELECT Department,
SUM(Marks) AS TotalMarks
FROM Students
GROUP BY Department;
```

---

## Output

| Department | TotalMarks |
| ---------- | ---------- |
| CSE        | 248        |
| ECE        | 95         |
| EEE        | 76         |
| IT         | 173        |

---

## Internal Calculation

```text
CSE

90

+

88

+

70

=

248
```

# Lesson 7: Multiple Aggregate Functions

```sql
SELECT
Department,
COUNT(*) AS TotalStudents,
SUM(Marks) AS TotalMarks,

MIN(Marks) AS LowestMarks,
MAX(Marks) AS HighestMarks
FROM Students
GROUP BY Department;
```

---

Output

| Department | TotalStudents | TotalMarks | AverageMarks | LowestMarks | HighestMarks |
| ---------- | ------------- | ---------- | ------------ | ----------- | ------------ |

| ECE        | 1             | 95         | 95.00        | 95          | 95           |
| EEE        | 1             | 76         | 76.00        | 76          | 76           |
| IT         | 2             | 173        | 86.50        | 82          | 91           |

# Lesson 8: GROUP BY Multiple Columns

Query

```sql

COUNT(*)
FROM Students
GROUP BY Department, Gender;
```

---

Output

| Department | Gender | COUNT(*) |
| ---------- | ------ | -------- |
| CSE        | Male   | 2        |

---

Internal Process

```text
Group by Department

↓

Within Department

↓

Group by Gender

↓

Count Rows
```

# Common Mistakes

## ❌ Selecting a Non-Grouped Column

Wrong

```sql
SELECT Name,
Department,
COUNT(*)
FROM Students
GROUP BY Department;
```

`Name` is neither grouped nor aggregated, so this can produce an error (especially when `ONLY_FULL_GROUP_BY` mode is enabled).

Correct

```sql
SELECT Department,
COUNT(*)
FROM Students
GROUP BY Department;
```

---

## ❌ Forgetting GROUP BY

Wrong

```sql
SELECT Department,
COUNT(*)
FROM Students;
```

This is invalid in standard SQL because `Department` is not grouped.

Correct

```sql
SELECT Department,
COUNT(*)
FROM Students
GROUP BY Department;
```
