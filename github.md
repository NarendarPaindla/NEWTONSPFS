**GitHub** is a platform used by developers to **store, manage, track, and collaborate on code/projects**. It is mainly used for **version control** using a tool called **Git**.

### Simple Definition

GitHub is like **Google Drive for code**, but with extra features for developers such as:

* Tracking changes in code
* Team collaboration
* Project management
* Version history
* Hosting projects online

### Why GitHub is Used?

1. **Code Storage (Repository)**

   * Developers store projects in a place called a **Repository (Repo)**.
   * Example: A React project, Java project, Python project.

2. **Version Control**

   * Tracks every change made to code.
   * If something breaks, you can go back to an old version.

3. **Collaboration**

   * Multiple developers can work on the same project.
   * Example: One person works on frontend, another on backend.

4. **Backup**

   * Your code is safely stored online.

5. **Portfolio**

   * Developers showcase projects to recruiters.
   * Companies check GitHub profiles during hiring.

### Key Terms in GitHub

#### 1. Git

Git is a **version control system** used to track changes in code.

#### 2. Repository (Repo)

A folder/project stored on GitHub.

Example:

```text
StudentManagementSystem/
│── src/
│── public/
│── package.json
│── README.md
```

#### 3. Commit

Saving changes with a message.

Example:

```bash
git commit -m "Added login feature"
```

#### 4. Push

Upload local code to GitHub.

Example:

```bash
git push origin main
```

#### 5. Pull

Download latest code from GitHub.

Example:

```bash
git pull origin main
```

#### 6. Branch

A separate copy of code for development.

Example:

* `main` → Original project
* `feature-login` → Login development

#### 7. Merge

Combining branch code into main project.

#### 8. Fork

Copying someone else's repository to your account.

#### 9. Clone

Downloading repository to local system.

Example:

```bash
git clone repository-url
```

### Real-Time Example

Suppose you are building **VillageBasket**:

* You create a GitHub repository.
* Frontend code → React Native
* Backend code → Node.js
* You push code daily.
* If an error occurs after new changes, GitHub lets you revert to old code.
* If another developer joins, they can clone and contribute.

### Basic GitHub Workflow

```text
Create Project
      ↓
git init
      ↓
git add .
      ↓
git commit -m "Initial commit"
      ↓
Create GitHub Repository
      ↓
git remote add origin <repo-url>
      ↓
git push -u origin main
```
