# Problem 1: Student Grade Management System (15 Marks)

Create a Python program to manage student grades.

### Requirements:

* Accept student name
* Accept marks for **3 subjects**
* Calculate:

  * Total marks
  * Average marks
  * Grade

### Grade Criteria:

| Average  | Grade |
| -------- | ----- |
| 90+      | A     |
| 75–89    | B     |
| 60–74    | C     |
| 40–59    | D     |
| Below 40 | Fail  |

### Sample Output:

```text
Enter Student Name: Rahul

Enter Subject 1 Marks: 80
Enter Subject 2 Marks: 90
Enter Subject 3 Marks: 70

Total: 240
Average: 80.0
Grade: B
```

### Concepts Covered:

* Variables
* Conditions
* Functions
* Arithmetic operators
