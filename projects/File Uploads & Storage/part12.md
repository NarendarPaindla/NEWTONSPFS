# What is a Pre-Signed URL?

A Pre-Signed URL is a **temporary secure URL** generated by AWS.

It allows someone to

* Upload

or

* Download

a file

without exposing AWS credentials.

Example

```text
https://bucket.s3.amazonaws.com/profile.png

?X-Amz-Algorithm=...

&X-Amz-Credential=...

&X-Amz-Signature=...
```

This URL contains a temporary signature created by AWS.

# Production Storage Service

Example method

```python
import uuid


class S3StorageService:

    @classmethod
    def generate_upload_url(
        cls,
        category: str,
        extension: str,
        content_type: str
    ):
        filename = f"{uuid.uuid4()}{extension}"

        object_key = f"{category}/{filename}"

        url = cls.s3_client.generate_presigned_url(
            ClientMethod="put_object",
            Params={
                "Bucket": settings.aws_s3_bucket,
                "Key": object_key,
                "ContentType": content_type,
            },
            ExpiresIn=300
        )

        return {
            "upload_url": url,
            "object_key": object_key,
            "expires_in": 300,
        }
```

# API Endpoint


# Production Best Practices

✅ Use short expiration times (5–15 minutes).

✅ Validate file type and expected object key before generating the URL.

✅ Authenticate the user before generating URLs.

✅ Authorize access to the requested resource.

✅ Store only the object key (or URL) in the database after a successful upload.

✅ Consider using bucket policies and server-side encryption for additional security.

# Interview Questions

### 1. What is a Pre-Signed URL?

A temporary, signed URL generated by AWS that allows a client to upload or download a specific S3 object without exposing AWS credentials.

---

### 2. Why are Pre-Signed URLs used?

They allow clients to communicate directly with S3, reducing backend bandwidth, CPU usage, and improving scalability.

---

### 3. What does `ExpiresIn` do?

It specifies how long the generated URL remains valid.

---

### 4. Which Boto3 method generates a Pre-Signed URL?

```python
generate_presigned_url()
```

---

### 5. Why should the backend still be involved if the client uploads directly to S3?

The backend authenticates the user, authorizes the operation, generates the secure URL, and records the uploaded object's metadata (such as the object key) in the database after the upload.
