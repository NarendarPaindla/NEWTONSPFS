# 1. Introduction

Before learning more HTML syntax, it is important to understand:

> Where did HTML come from?

> Why was HTML invented?

> Who invented HTML?

> What problems existed before HTML?

Most beginners learn HTML tags directly.

```text
Why HTML Exists

Why Browsers Exist
Why Websites Exist
```

All these technologies were born together.

# What Was the World Like Before HTML?

Before HTML:

```text
No Google
No YouTube
No Facebook
No Amazon
No Online Shopping
No Social Media
No Modern Websites
```

Computers existed.

Networks existed.

But information sharing was difficult.

---

## The Problem

Different computers stored information differently.

Example:

```text
Computer A
   |
Different Format
   |
Computer B
```

Sharing information between organizations was complicated.

---

## Real-World Analogy

Imagine every country speaking a completely different language with no translator.

Example:

```text
Person A
  |
Language A
  |
Cannot Understand
  |
Language B
  |
Person B
```

Similarly:

```text
Computer A
  |
Different System
  |
Cannot Easily Share
  |
Computer B
```

A universal solution was needed.

---

# 2. Core Theory

# CERN and the Beginning of the Web

To understand HTML, we must first understand CERN.

---

## What is CERN?

CERN is a scientific research organization.

Official name:

```text
European Organization for Nuclear Research
```

Located in:

Geneva

---

## Why CERN Was Important

Scientists from different countries worked together.

Problem:

```text
Research Documents
Scientific Papers
Project Data
```

were stored on different computers.

Sharing information was difficult.

---

## Challenge Faced by Scientists

Imagine:

```text
Scientist A
   |
Computer A
```

and

```text
Scientist B
   |
Computer B
```

Both needed access to information.

There was no simple universal system.

---

# Enter Tim Berners-Lee

The person who changed the Internet forever.

Tim Berners-Lee

---

## Who Was Tim Berners-Lee?

Computer scientist working at CERN.

His goal:

```text
Make Information Easy To Share
```

between researchers.

---

## The Big Idea

Instead of isolated documents:

```text
Document A

Document B

Document C
```

Create linked documents.

Example:

```text
Document A
     |
     v
Document B
     |
     v
Document C
```

Documents could reference each other.

This idea became:

```text
HyperText
```

---

# What is HyperText?

HyperText means:

```text
Text Connected Through Links
```

---

## Example

Book Navigation:

```text
Page 1
 ↓
Page 2
 ↓
Page 3
```

Fixed sequence.

---

HyperText:

```text
Page A
 ↓
Page B

 ↓

Page C

 ↓

Page D
```

Users can move freely.

---

## Why HyperText Was Revolutionary

Before HyperText:

```text
Linear Navigation
```

After HyperText:

```text
Non-Linear Navigation
```

Users could jump instantly between related information.

---

# Birth of the World Wide Web

Tim Berners-Lee proposed a system.

The system contained three major inventions:

```text
HTML
HTTP
URL
```

These are still used today.

---

# Invention 1: HTML

Purpose:

```text
Structure Documents
```

Example:

```html
<h1>Research Paper</h1>

<p>Scientific Content...</p>
```

---

# Invention 2: URL

URL means:

```text
Uniform Resource Locator
```

Purpose:

```text
Locate Resources
```

Example:

```text
https://example.com
```

---

## Real-Life Analogy

House:

```text
Person
 |
House Address
```

Internet:

```text
Website
 |
URL
```

---

# Invention 3: HTTP

HTTP means:

```text
HyperText Transfer Protocol
```

Purpose:

```text
Transfer Web Documents
```

---

## Simple Example

Browser says:

```text
Please send webpage.
```

Server replies:

```text
Here is webpage.
```

Communication rules are defined by HTTP.

---

Tim Berners-Lee

Purpose:


---

## Historical Significance

This was the beginning of:

```text

Modern Internet
```




# 9. Common Mistakes

### Mistake 1

Thinking Internet and Web are the same.

Wrong:

```text
Internet = Web
```

Correct:

```text
Web runs on the Internet.
```

---

### Mistake 2

Thinking HTML created the Internet.

Wrong:

```text
HTML created Internet
```

Correct:

```text
Internet already existed.
HTML helped create the Web.
```

---

### Mistake 3

Confusing URL and HTML.

Wrong:

```text
URL = HTML
```

Correct:

```text
URL locates.
HTML structures.
```
