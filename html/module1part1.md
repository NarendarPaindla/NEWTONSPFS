1. Introduction

What is a Website?

A website is a collection of related web pages that are accessible through the internet using a web browser.

Examples:

Google

YouTube

Amazon

Facebook

College Websites

Company Websites

Personal Portfolios


A website can contain:

Text

Images

Videos

Audio

Forms

Links

Interactive elements


Every website has a unique address called a URL (Uniform Resource Locator).

Example:

https://www.google.com
https://www.youtube.com
https://www.amazon.com


---

Why Was a Website Created?

Before websites existed:

Information was stored locally.

Sharing information was difficult.

Communication was slow.

Businesses could not easily reach global customers.


The invention of websites solved these problems by allowing information to be accessed from anywhere in the world.

2. Core Theory

Understanding a Website

Think of a website as a digital building.

Example:

Building
│
├── Room 1
├── Room 2
├── Room 3
└── Room 4

Similarly:

Website
│
├── Home Page
├── About Page
├── Contact Page
└── Services Page

Each page serves a specific purpose.


---

Internal Working

When a user visits a website:

Step 1

User enters URL

www.amazon.com

↓

Step 2

Browser requests webpage

↓

Step 3

Server sends webpage

↓

Step 4

Browser displays webpage

9. Common Mistakes

Mistake 1

Thinking Website and Webpage are same.

Wrong:

Website = Single Page

Correct:

Website = Collection of Pages


---

Mistake 2

Believing Internet and Website are same.

Wrong:

Internet = Website

Correct:

Internet = Network
Website = Resource on Network

12. Interview Questions & Answers

Basic

Q1. What is a website?

Answer:

A website is a collection of related web pages accessible through the internet using a web browser.


---

Q2. What is a webpage?

Answer:

A webpage is a single document within a website.


---

Q3. Give examples of websites.

Answer:

Google, Amazon, YouTube, Facebook, LinkedIn.


---

Intermediate

Q4. Difference between website and webpage?

Answer:

Website = Collection of pages
Webpage = Single page


---

Q5. Why are websites important?

Answer:

They help businesses, education, communication, marketing, and information sharing.


---

Advanced

Q6. Explain website architecture.

Answer:

A website contains interconnected pages linked through navigation structures that allow users to move between sections.


---

Q7. Explain the role of browsers in websites.

Answer:

Browsers request web pages from servers, interpret HTML, and display content to users.
